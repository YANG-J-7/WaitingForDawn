# 网格草地独立预览

日期：2026-11-11。状态：候选，等待视觉反馈。用户选择先制作独立预览。

## 运行与操作

Godot 4.7 打开 `res://tools/preview_grid_grass.tscn`，按 F6 运行当前场景。

F6运行当前编辑器标签页，F5运行正式主场景。2026-11-11修复了旧标签页`preview_moonlake_3d_level.tscn`引用已删除脚本导致的空地图：该旧路径现在仅兼容转接到本草地预览，不再继承游戏HUD，也不恢复已移除的3D功能。建议后续统一使用上面的新场景路径。

- G 或顶部开关：显示／隐藏逻辑网格。
- W 或“风吹”开关：关闭／恢复叶片风动；空格暂停／继续风时钟。
- 滚轮：以鼠标为锚点缩放；中键拖动：平移。
- Home 或“查看全图”：恢复完整样区视野。
- 占地下拉框：选择1×1、2×2、4×4示意；鼠标悬停显示占地，越界时红框加叉。

这里的占地仅演示尺寸和边界，没有实际建造、资源消耗、单位、战斗、商店与对局计时。

## 尺寸与层次

| 项目 | 规格 |
|---|---|
| 逻辑格 | 32×20，每格36世界像素，样区1152×720 |
| 地表视觉 | 连续世界坐标细草，三个固定偏移混合，不在逻辑格边缘重启纹理 |
| 图像来源 | `assets/map/grass_hd_v1/detail.png`和既有透明草叶`wind/idle-1.png`；没有覆盖原素材 |
| 原生纹理 | 1448×1086细草覆盖144×108世界范围；384×384透明草叶原稿 |
| 配色 | 对照第一关`dressed-reference.png`改为更亮的灰绿草色，基色约`#3C5846`，保留草叶明暗 |
| 风动 | 4144株透明草叶固定种子散布，共用一次MultiMesh与受控时钟，叶根固定、叶梢最大约0.85世界像素 |
| 地形 | 全部草地，可走、可建，移动代价1.0，海拔0 |
| 玩法数据 | 使用独立 `GridMapModel(32,20)`；不读取正式第一关地形，不写入正式关卡 |
| 配置 | `map.json` 保存布局、来源、格属性默认值与空对象层 |
| 渲染 | 静态地面、风动草叶、网格、占地和UI分层；网格和地面不随风动 |

网格采用正交平面。当前第二版按用户反馈取代初版深蓝四块混铺：颜色更亮、细草更密，且没有规则方块边界。草叶高密度源图缩小显示，玩法格大小不等于纹理分辨率。正式第一关入口、地形、美术、镜头及动态状态保持原状。

## 验证与限制

第二版专项无界面25项、旧入口真实GL35项通过，覆盖640格属性与坐标、占地边界、镜头、风时钟暂停／关闭／恢复／复位和图像差异：草叶随时刻变化，隐藏草叶后的地面0像素变化，关闭风动时完整画面0像素变化。保存4张静态截图与24帧动态序列，已检查总览／近景。证据在本地`tests/reports/images/grid-grass-wind-2026-11-11/`及`.codex-temp/grid-grass-wind-legacy-gl.log`，动画为`wind-preview.gif`。测试目录依项目要求不提交。初版网格15项、地形70项是上一轮基线，本次没有重跑无修改的正式关卡全量。

已在用户当前Godot编辑器实际F6启动第二版，观察到灰绿草地、风吹开关与占地提示；G键可关闭网格，实际滚轮可缩放。预览保持运行，风吹默认开启。

底层细草静态，风动作用于独立草叶层；不宣称原稿中每片烘焙草叶都已单独绑定。动态层目前只有一种叶型，长期重复感、4K性能和最终审美仍待复核。没有新增湖岸、山地或天气机制。下一步确认配色、密度与风幅后，再评估变体和正式关卡迁移。
