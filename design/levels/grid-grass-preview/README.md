## 运行与操作

Godot 4.7打开`res://tools/preview_grid_grass.tscn`，按F6运行当前场景。旧`preview_moonlake_3d_level.tscn`兼容转接本预览，避免残留标签引用已删除脚本而显示空地图。F5仍运行正式主场景。

- G或顶部开关：显示／隐藏逻辑网格。
- 滚轮：以鼠标为锚点缩放；中键拖动：平移。
- Home或“查看全图”：恢复完整样区。
- 占地下拉框：1×1、2×2、4×4示意；越界显示红框与叉。

按用户最新要求完全移除独立预览的动态草叶层、风时钟、风吹开关和W／空格动画控制。这里不运行建造、单位、战斗或对局计时。

## 尺寸与渲染

样区32×20逻辑格，每格36世界像素，共1152×720。独立`GridMapModel`保持640格可走可建，移动代价1.0、海拔0。玩法网格大小与贴图分辨率分开。

地面使用世界坐标连续采样，原稿覆盖216×216世界范围，三角格的固定偏移混合削弱规则重复，不旋转光向或按逻辑格重启纹理。混合和缩小可能让局部细草柔化，不能以渲染连续性代替原稿拼铺质量。网格和占地独立叠加；`map.json`登记当前来源及静态状态。
