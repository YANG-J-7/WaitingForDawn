# 第一关湖岸与湖水接入验证

2026-11-13，Story-033继续开放。用户授权按设计图排布接入湖岸与湖水。入口为`res://src/main/main.tscn`，F5可查看正式第一关；旧`tools/preview_lake_shore.tscn`仍是独立素材样区，不代表本轮关卡布局。

实现：第一关组件装配加入lake角色，东北水域接上边界，东侧及东南两处凹湾/岩岬按设计图布置；中央草地、57处碎石花草、10组六块泥地和环境制图模式保留，水面覆盖已进入水域的旧装饰。小地图直接渲染同一组件，水域多边形同时生成显示遮罩和2741个保守水格，不能通行或建造。旧四出生点到主城外围路径回归保持。山体、石梯和树林仍未恢复。

首轮水平岸段剪切铺设在实景中过直，已改为以原三款岸段作形态/材质参考，内置image_gen生成东北和南部双湾两份定向适配图，分别原生1207×1303与1774×887。保留全部原稿/提示词/布局指南和哈希。实际3556×2880覆盖PNG是装配输出，不将其标为原生生成细节；最终素材与元数据见`assets/levels/level_001/lake/`。源图边缘的有意连续接口已目检，不放宽输出触边或裁切要求。

水面/浅水反射、固定月光区域和10处独立水花共用12秒/60Hz时钟；岸石原画固定UV。新控制图将纯水、岸石保护和深浅权重分离，水花仅出现在水侧。修正一处被保护图完全裁掉的水花落点后，十处实际可见。制图模式暂停按钮开放给环境动画，重开复位；其余对局模式原有暂停门槛保持。正式地表使用现阶段原画色彩，尚无新岸层的昼夜主光调色联动。
