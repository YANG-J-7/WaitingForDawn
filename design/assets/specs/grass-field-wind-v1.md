# 全图草地风动设计 v1

日期：2026-10-27。状态：静态接入验证后的设计稿，尚未实现动画。用户要求取消昆虫，只保留覆盖全图草地区域的风动。

## 视觉与范围

沿整张地图传播低幅度轻风，方向连贯、强弱缓慢变化；邻近草叶动作相关，远处相位不同，不出现整幅草皮滑动、相同方块同步翻动或重复摆放同一大草簇。风从左上向右下为初始美术参数，可在实景调整，不影响天气或战斗规则。

全图指所有可见草地区域，而不是所有像素。平原、林间、山台的草叶需要进入统一控制；岩石、石阶、泥土、水面、树干、建筑、主城石土底座保持静止。当前静态高清层只覆盖平原，不能直接把平原遮罩称为全图草叶遮罩。山台及独立岩缘素材中的草叶要补齐匹配的控制层后，才能验收全图覆盖。

## 素材与实现顺序

1. 对现有细节原稿制作与其完全对齐的草叶控制贴图，区分根部、叶梢和非草土壤；必要时用内置image_gen按可见原稿编辑叶层，再做确定性去底与对齐。草根权重0、叶梢权重1、土壤0，必须目检，不能仅用亮度猜测所有亮点都是草叶。
2. 原土层保持静态；叶层与控制层使用相同的世界坐标、三角格偏移和混合权重。只在叶层位移，避免连土壤和根部一起扭曲。先在主城外和平原四块交点验证，再扩展山台/林缘；独立岩缘上的草叶使用同一世界坐标风场。
3. 使用一个受游戏状态管理的环境时钟。风向和强度是全图公共参数，位置相位来自世界坐标；不为每个地砖建立计时器，不直接使用不会自动暂停的着色器TIME。
4. 暂停、胜利、失败时冻结；重开时归零；暂停中移动相机只改变可见区域，草叶姿态不跳变。提供环境动画关闭开关，关闭后回到已验证静态草地。

## 初始调校参数（待实景验证）

| 参数 | 初值/范围 | 用意 |
|---|---|---|
| 基础风向 | 归一化(0.94,0.34) | 与画面方向保持稳定 |
| 叶梢位移 | 0.25～0.6世界像素，阵风不超过1.0 | 最大倍率可见、不过度晃动 |
| 叶片轻摆周期 | 2.8～4.6秒 | 轻微变化，无机械同拍 |
| 大尺度风带 | 600～1200世界像素 | 跨越贴图分块，不暴露方格 |
| 阵风包络 | 9～17秒缓入缓出 | 留出安静时段 |
| 全图缩远 | 衰减位移，保留低对比风带 | 避免细草闪烁和水波感 |

这些值是美术起点，不是天气系统批准参数。整体草色变化应极小，不能用明暗扫屏冒充草叶弯动。

## 验收

录制主城、平原、林缘、山台以及分块交点的默认/最大倍率动态实景，至少包含一次完整阵风与一次暂停后平移。根部和非草像素保持静态；同一世界位置在不同分块和相机位置的姿态一致；重开与关闭动画无残留。覆盖1280×720和4K渲染目标，并比较静态/风动开启时的GPU帧耗；超过预算则降低风层采样成本，不牺牲原生草叶密度。

长时间观察至少60秒，检查明显动作周期、整片同步摆动和重复草簇；这不能替代60分钟玩法自然长局验收。当前昆虫方案彻底取消，不留运行调度或预留虫子数量。
