# ASSET-0004：低噪水面材质

状态：specified，范围未批准，未生成，未接入；日期2026-10-27。审核：用户/指定美术负责人。所属[生产计划](../map-kit-v2-production-plan.md)。

- 用途：湖泊闭合多边形内填充，2种低噪变化；水域边界是数据，湖岸独立。
- 视觉：深冷蓝、小面积柔和月光纹、没有强烈统一横带；岸边可用深度权重调色但不制造假浅滩通路。
- 镜头/密度：4K/1.6建议8、最低6.4有效纹素/世界单位；远景高光受控。
- 尺寸：2048×2048覆盖256×256世界；首样1页，第二变体后续。
- 格式/透明度/帧：不透明RGB PNG、静态1帧；水纹运动以后由独立小幅引擎效果实现，不改水域碰撞。
- 命名/锚点：`water_detail_a.png`；世界UV、同向光，不随湖组件平移重置花纹。
- 预算：每2048 RGBA8+mip约21.33MiB；动画不批量生成全幅高分帧，Shader取样单独测量。
- 依赖：湖岸结构、湖域语义、统一光照；不批准水上单位/采集/结冰机制。
- 目标：`assets/map_kits/moonlit_v2/water/`；记录原稿、提示词与哈希。

手写生成提示词：绘制可平铺的冷蓝月夜湖水表面材质，高清像素感游戏画面、安静低对比波纹、小面积月光碎纹、全幅连续；使用已查看项目地图的水色和左上光向，不画岸线或任何物体，缩远仍是一片清楚安静的水面。

禁止项：岸、岛、船、建筑、角色、鱼、月亮倒影大图案、天空、文字、白色满屏噪点、照片、模糊。

验收：平铺、两种变体色域一致、闭合水域不漏底、岸缘过渡不开放通行、4K/缩远水纹稳定；动画/暂停为后续验证。
