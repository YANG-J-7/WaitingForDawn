日期：2026-11-11。状态：candidate；仅接入独立草地预览，未替换正式第一关。

运行预览覆盖216×216世界范围，连续世界坐标固定偏移混合，不旋转素材。逻辑格仍为36世界像素。动态草叶、风时钟和相关控制均移除。

原稿未做像素闭边处理；可辨草簇的长期重复、混合柔化、4K观感及最终视觉接受仍待复核，不称严格无缝或生产美术完成。验证与操作见[样区文档](../../levels/grid-grass-preview/README.md)。
