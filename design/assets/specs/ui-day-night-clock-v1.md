# UI-DAY-NIGHT-CLOCK-V1：黎明计时胶囊与日月转换

- 日期：2026-10-09；需求：用户红框区域与设计图不符，并明确要求使用 `generate2dsprite` 制作日月转换动画。
- 视觉：深蓝圆角胶囊、蓝灰双层轮廓，左下绿黄进度弧，蓝色月牙及小星，白色“黎明”、金色实时时间。胶囊142×44逻辑占位，背景从顶栏上方6像素到下方5像素，文字不烘焙。
- 帧：8帧月牙→金色光芒太阳，2行4列，128×128固定公共单元，512×256透明PNG；共用缩放与中心，显示40×40逻辑像素。
- 生成：内置图像生成，纯品红背景，独立资产；用技能脚本去背景、分帧、共享缩放与严格边缘QC。源稿与完整提示词、清理稿、图集、帧、GIF和元数据一并保留。
- 动画：只读取60分钟对局有效计时；圆弧表示整局进度，最后5分钟在相邻日月帧之间淡入，归零显示太阳。暂停停止，继续恢复；重开回到月牙。展示不修改威胁、经济、地形、天气或胜负规则。
- 输出：`assets/ui/day_night_clock_v1/`；运行脚本 `src/gameplay/art/day_night_clock.gd`。
