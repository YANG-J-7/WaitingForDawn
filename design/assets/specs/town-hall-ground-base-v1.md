# 主城地面底座设计 v1

日期：2026-10-26。依据用户对最大倍率主城贴地效果的反馈，底座明确包含地面和周围草地。用户已确认设计方向，独立底座已接入并完成左后侧红框修正，最终运行观感待复核。

## 视觉构成

1. 墙脚低石基：沿现有建筑底边露出一层部分埋入土中的灰蓝石块，窄接触影承接墙体；用少量苔痕和短草打散边缘。厚度克制，避免主城变成高台。
2. 门前地面：已有台阶落到磨损石板、压实泥土混合的院前空地，半埋碎石和细草逐渐取代完整石板。视觉宽度目标约主体的1.15倍，前向延伸约25～35世界像素，实际范围待图稿及运行验证确定。
3. 周围草地：约20～30世界像素宽的不规则过渡带，包含压平草、短草、稀疏小草簇、土粒和细碎石；与当前地图细草的色调、密度和纹理尺度一致。外缘散开，避免整圈描边、石圈、矩形草坪或椭圆贴片。
4. 夜景融合：沿用左上冷月光和右下投影，阴影中保留地面纹理，暖光仅邻近入口。墙脚和地表具有连续亮度，减少主体锐利边缘的剪贴感。

## 素材拆分原则（已实施）

用户确认方向后，已独立生成可供运行的地面贴花：低石基/石土院前地面及渐疏草缘；必要时另拆近侧草叶遮挡。运行素材使用透明不规则边缘，远离主体的透明区保持干净，不从场景设计图直接切出生产地块。独立阴影与地面底座分层，避免重复叠黑。

接入后须在默认和1.6倍率复核墙脚、台阶落点、草缘接缝、单位经过及相邻建筑遮挡，并复测启动、重开与相关建造/运输测试。装饰延伸的范围不能被误作新的建筑硬占格。
