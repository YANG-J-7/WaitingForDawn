# 地图美术圣经 v2 修订草案

> 日期：2026-10-27；状态：提案，未批准，未生产。
> 依据：[模块化地图方案](../gdd/modular-level-map-system.md)、[现行美术圣经](art-bible.md)、[技术偏好](../../docs/project/technical-preferences.md)。
> 本文仅修订地图环境与建筑融合规范，保留角色、HUD与已接入素材。评审后再把通过条款合并进正式美术圣经，不将旧候选自动标为approved。

## 1. 一句话身份与设计测试

**冷蓝月夜里的可经营山湖聚落：地形清楚、地面安静，暖金灯火与行动单位始终可辨。**

推荐视觉：高清像素感环境，保留块面和轮廓节奏，以原生高密度细节支持连续缩放。备选为严格低分辨率像素画，但需收紧镜头/整数倍率且会出现可见像素块，不符合本轮优先解决的放大观感。写实照片质感不纳入候选。

三项设计测试：默认0.72倍率两秒识别主城/资源/敌人方向；1.6倍率观察岸线/草叶/地基不出现大块插值或矩形补丁；总览仍能读出山湖轮廓、通路与扩张空间。使用实际物理渲染截图，不在聊天缩略图上单独判清晰。

## 2. 情绪、光照与状态

常态：低对比冷地表，暖点集中在聚落；主光保持项目现有左上冷光、向右下投影。结构件不得因旋转获得另一套光向。暂停冻结环境动画，保持可查看地图；威胁预告通过方向/符号表达，避免全屏染红。

建造态显示占地、入口与失败原因，关闭或淡化被预览遮挡的低矮装饰。天气只预留覆盖层，不批准雨雪种类或数值；任何未来覆盖不得遮掉角色、路线和格位。最后5分钟现有日月HUD变化不推定整张地形已经切换白昼。

## 3. 形状语言

草地为低而软的片状节奏；湖岸用连续弧线与碎石小节奏；山体用有逻辑的草台、崖唇和明确直立岩面；石梯正面可辨、上下端落到实际平台，不能悬挂或暗示跨崖捷径。树林以三角树冠组成疏密簇，轮廓不呈矩形。

建筑保留主城厚重、塔楼高窄、生产建筑低宽的已有区分；入口/脚点比屋顶包围盒更重要。农民头肩与持物、狼前倾长轮廓维持，环境不能通过提高亮度和碎纹压过行动主体。

## 4. 色板与语义

沿用现行目标色：深影`#0B1724`、地面`#203B49`、冷边`#6E94A7`、石路`#56647A`、木`#684A3A`、暖火`#FFD071`、交互金`#E6B75D`、危险红`#D9545A`、友方绿`#70C49A`。材质可有色阶，不强行把高清原稿量化为固定64色。

草台、平原和林缘共享草材质色域；远水/岩面亮度不得与金色交互边争抢。跨组件材质边缘先匹配低频颜色，再加细节，不允许各自手调亮度后靠大羽化掩盖。去色复核道路、敌我与落点；合法实线+确认符号，非法交叉+文字，不只用红绿。

## 5. 角色与动画的环境配合

本轮不重做角色/敌人/投射物，不把它们烘焙在地图组件中。样区直接使用当前农民、守卫、狼与主城，检查头肩、攻击轮廓、选中和目的地提示。

环境动画优先共享风场、局部叶梢控制和水面小幅变化；地面土壤/岩石不摆动，草叶不得越界开出假路。风动、可减少动态效果设置与视觉LOD独立于碰撞；暂停/重开使用有效游戏时间。动画实际制作需在静态小样通过后排期。

## 6. 环境、构图与镜头

维持3/4俯视斜角、正交世界平面，不采用透视消失点或把网格转成菱形等距。世界坐标、碰撞边、脚点统一；画出来的崖高不自动等于射程或伤害加成。

推荐中型山湖组件、连续基础材质、小型独立地物。备选全TileSet更适合大量重复规则格，但本项目大山体需要多层轮廓，优先混合而不强制全小图块。湖面和山体可以独立移动，通用草地底层必须完整。

细节分三个频段：大尺度色场和结构轮廓承载构图；中尺度岩块、岸石和草疏密传递材质；小尺度叶片和裂缝只服务近景，缩远逐渐消隐。三种频段不能都烘焙成每块不同的大图。

地形组件统一锚点和世界采样；特殊形状逐件制作，岸段/崖段有直段、凸凹角、端头及交会验证。每件带视觉范围与逻辑范围，遮挡分片进入公共排序域；真实角色在前后行走验收。

镜头推荐操作cover限位、独立fit总览、外延景观收边。所有边缘均在实际地图视口内验证；远景外延禁走禁建，不画出吸引玩家但无法到达的资源点。

## 7. UI、图标与VFX

复用现有HUD、商店、手牌与小地图入口。新地图只提供底图/资源符号位置和视野框数据，文字由引擎绘制。调试端口、出生多边形和层级标记只存在编辑器/调试视图。

选中、落点和路线在单位/地物之上独立绘制，不依赖把整座山或整片林设高Z。总览可以用放大符号保留资源辨识，不尝试把几像素农民放大成常态巨人。天气/风VFX不拥有玩法数据。

## 8. 技术尺寸、LOD与预算

| 内容 | 提案标准 |
|---|---|
| 玩法格 | 保持36世界单位；不是36×36纹理限制 |
| 环境密度 | 4K实际k=4/最大1.6时最低6.4，生产建议8 texel/世界单位 |
| 源与输出 | 记录原生有效细节尺寸和覆盖范围；插值扩图不计新增细节 |
| 单纹理 | 优先2048，4096需预算例外；结构组件由多片和共享材质组成 |
| 格式 | 原稿与运行PNG；独立物件RGBA，地表尽量不透明；语义遮罩与颜色图分开 |
| 导入 | 高清环境Linear+mipmap；现有像素角色保留自己的过滤策略；有损压缩另验 |
| 图集 | 小型同类装饰共页；扩色/隔离按mip深度测，重要结构独立页 |
| 材质 | 草/土/岩/水共享材质族；优先有限取样，不能每格一份独立材质 |
| 2D几何 | 普通物件四边形，湖岸等允许简化多边形；无3D面数/材质槽生产范围，2D网格仍需实测 |
| LOD | 按投影像素控制细节，15%滞回候选；地形规则和碰撞不消隐 |
| 常驻纹理 | 地图相关目标256MiB，包含mip，最低硬件未定，样区后校准 |

高密度完整地表与256MiB目标冲突时，优先复用材质、拆局部结构、远景简化；不默默降低近景清晰度，也不把全图巨大合成图当作生产资产。

建筑底座规格包含占地、脚点、硬地基、柔边、接触影、可绘制地形/层级和植被清理遮罩。邻楼底座重叠、临水临崖、拆除恢复都要有真实样例。详细生产规格见[素材计划](../assets/map-kit-v2-production-plan.md)。

## 9. 参考与禁区

正向参考是项目当前主城的冷暖与块面、已接入高清细草的源密度、现有山湖的大地形阅读；不照搬其他游戏地图布局、商标或独特建筑组合。现有概念图只作方向参考，不能直接切最终结构件。

禁止矩形草地贴片、各块各自带大面积地板/投影、随意旋转方向光素材、草羽化覆盖硬崖、跨层底座、把生物烘焙进地面、柔焦掩盖接缝、无许可来源、只看全图就认定近景合格。不同画幅不得拉伸地图凑比例。

评审建议集中三点：高清像素感环境方向；操作镜头/全图总览分工；首批只制作一个互动样区。其余数值是样区可调整初值，不作为既定玩法。
