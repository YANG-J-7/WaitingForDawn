# Waiting for Dawn 美术圣经 v1

> 日期：2026-09-22。依据用户提供的夜间聚落参考图制定。该图用于视觉方向，不提供玩法规则、资源数值或已批准的地形／天气机制。19 张独立图位于 `assets/art_candidates/night_set_v1/`，已按原型比例接入当前游戏原型，状态仍为候选。

## 1. 视觉身份

**冷蓝月夜包围暖金聚落：玩家在远景中一眼找到主城、生产点、防线和来袭威胁。**

设计测试：把场景缩至当前 960×540 逻辑视口、相机默认缩放 0.72 后，玩家应在两秒内指出主城、道路、可交互建筑与敌方方向。识别必须依靠轮廓、位置和明暗；去色后仍应成立。

参考图提供冷暖关系、俯视斜角、暗色密林、火把节点、羊皮纸卡牌与深蓝 HUD。不得复制其建筑轮廓组合、徽记、排版、数值、构图或把整张图裁成游戏素材。当前候选图为重新生成的独立对象。

## 2. 情绪、氛围与光照

| 状态 | 画面要求 |
|---|---|
| 常态夜间 | 地面低对比冷蓝；树林边缘可辨但不抢主城；窗户、火把形成少量暖点。 |
| 威胁接近 | 路线和敌人轮廓提高对比；红色仅用于敌方、危险和生命损失，不能把整屏染红。 |
| 建造／选中 | 合法范围用金色细边与地面投影，非法用红色形状标记；不靠颜色单独表达。 |
| 暂停／结算 | 保留地图背景与当前状态，压暗非操作层；主城和关键信息仍可见。 |
| 天气 | 仅约束未来制作方式：天气覆盖层不得抹去单位轮廓、路径和落点；具体天气种类和数值待 GDD 确定。 |

主环境光由左上方冷月光提供，暖光只从可解释的火把、灯笼、窗户发出。静态建筑图不画大面积外溢光晕，动态光和光照半径留给引擎。一个镜头中暖光面积目标小于可见地图面积的 15%。

## 3. 形状语言

- **主城**：最大且最稳定的屋顶和入口轮廓，底部厚重，可在密集建筑中区分；耐久状态在 UI 中表达。
- **生产建筑**：低宽形体加一件职业道具。伐木场用圆木与斧，农场用平行田垄，采石场用方石与推车。
- **防御建筑**：箭塔高窄、城墙横向重复、兵营有盾／枪的竖向标记。墙段两端应能拼接。
- **民居**：低矮、简单、少灯火，不能与主城争焦点。
- **友方单位**：头肩和手部在小尺寸下可见；动作方向清楚。敌方狼使用前倾低伏的长轮廓，威胁标识另由 UI 提供。
- **自然物**：针叶树以三角形大块分层，石头以低矮不规则块面；草和道路属于低频背景纹理。
- **UI**：深蓝直边容器加克制金边，卡牌使用暖纸张；按钮高亮必须有边框／形状变化。

统一 3/4 俯视斜角：能见顶面和正面，不混入正侧面或真实等距 45° 网格。画面不使用写实透视消失点。对象脚点在底部中心；碰撞与占地取脚点附近的地面，不按屋顶外缘计算。

## 4. 色彩与无障碍

下列颜色是制作目标色，允许为材质明暗做少量变化；候选图尚未量化到此色板。

| 角色 | 色值 | 用途 |
|---|---|---|
| 夜空／最深阴影 | `#0B1724` | 远景、树冠内暗部 |
| 地面基色 | `#203B49` | 草地和可行走地面的平均色 |
| 冷月边缘 | `#6E94A7` | 树、石、屋顶的少量亮面 |
| 石与道路 | `#56647A` | 道路、城墙、矿石的中亮面 |
| 木材 | `#684A3A` | 木架、墙、道具 |
| 火焰核心 | `#FFD071` | 窗户、火把、主城焦点 |
| 金色交互 | `#E6B75D` | 选中、可购买、重点数值 |
| 敌方危险 | `#D9545A` | 敌人生命、攻击预警 |
| 友方状态 | `#70C49A` | 生命、安全与正向状态 |
| 卡纸 | `#E6D4AD` | 手牌底色 |

色弱备用线索：合法建造使用实线轮廓和确认图标；非法使用交叉纹／禁止形；敌方同时用尖角轮廓、血条图标与方向提示；资源图标要靠轮廓区分木、食、石、铁、金。

## 5. 角色与动画

角色地图目标高度 20–32 逻辑像素，狼约 24–36 像素；图像源可以更大，但最终必须人工清理到统一像素网格。人物至少提供待机、四向移动、受击、死亡；狼至少提供移动、攻击、受击、死亡。守卫与农民用服装和持物区分，不依赖换色。动画优先 6–10 fps 的可读关键帧，火焰可 6–8 fps 循环，箭矢和命中短促明确。

当前 `villager.png`、`guard.png` 和 `wolf.png` 已在原型中显示，并用位移与明暗变化表现基础活动；源图仍是单姿态候选，未达到上述逐帧动作标准。

## 6. 环境、构图与镜头

地面目标已随权威网格统一为 36×36 逻辑像素正交 TileSet；道路需要直线、转角、T 字、十字、端点和草地过渡。水面需要岸线、转角和桥接口。草地基底频率低，树、石、草簇以独立装饰分层摆放，资源点不得被装饰遮住。2026-09-28已制作4个36×36无缝草地变体并接入运行地形层。

主城附近留清楚的建造与选择空间；道路是导航线索，不能暗示尚未实现的路径规则。大量树木应成簇但穿出可见空隙。近景对象在地图层按脚点 Y 值排序；高树和塔楼不得遮住 HUD 关键数值。当前镜头可缩放 `0.35–1.6`，需分别检查默认 0.72 与最小 0.35 下的轮廓。

建筑地图目标尺寸：民居／生产建筑约 64–96 像素宽，箭塔约 48×96，主城约 128×112；卡牌插图另做 128×96 或同等比例。候选图尺寸与细节明显高于地图目标，不能仅靠缩小自动变成一致像素画。

### 草地纹理密度补充（2026-10-08）

按用户要求，草地最大倍率不应出现明显粗像素方块。玩法网格仍为36世界像素，但运行草地图改用4个627×627原生变体、每块覆盖72×72世界像素；和主城一样保留细节源稿后缩小显示，不再降为36像素后放大。冷蓝月夜、低对比地面和暖色主城焦点不变，平原统一亮度0.88，保留原有岩面和坡脚。此补充覆盖下方对草地“36×36贴图”的旧尺寸建议，不改变建筑/单位尺寸或碰撞。

图集2508×627、共享64色、Lossless、Nearest、无mipmap；宽度超过1024优先建议是本轮原生细节保留的明确例外。RGBA8解码约6MiB，所有地块复用同一纹理。已检查全图、1.0和1.6倍率；未进行新纹理的多分辨率性能压力测试，最终视觉与缩远噪点仍待用户评审，不标记美术最终批准。

### 连续地形精修补充（2026-10-08）

用户新增要求整张地图放大不显粗像素。当前山坡、崖壁、湖岸和水纹使用四片区独立图像生成的高细节稿，合成3344×1882纹理，显示世界仍2880×1620；不再降采样后整数复制，不做64色量化。此连续底图及保坡采样明确采用Linear，不影响草地、建筑、单位和UI的Nearest。取消保护材质中的2世界像素取样量化，保留细岩缝、冷月亮边和接触阴影。下方除石轮廓向内退让以保护新岸线，平原仍统一0.88亮度。

实际生成片区约1628×966，合成前约10.5%尺寸规范，不声称一次生成原生4K或整图达到主城相同源密度。RGBA8底图解码约24MiB，未作新增纹理压力测试；目前只验证960×540真实GL、1.0/1.5/1.6镜头及接缝近景。保留整体构图而非逐点复制旧岸线，最终审美、自然边界走位和多分辨率性能待验；仍是固定地图候选，不标记正式模块化地块已完成。

## 7. UI、HUD、图标与特效

沿用 Story-026 已实现的单行顶栏、全宽手牌、建筑岗位浮层和右侧商店抽屉。图标按 24×24 逻辑像素制作，资源图形取木段、苹果、石块、铁锭、金币等单一剪影；在 1× 缩放时检查。文字由字体控件排版，不烘焙在图片中。卡牌建筑插图与地图单位共用形状语言，但应使用独立缩略图布局和较亮的纸面背衬。

火焰、击中、选中和放置预览分离成特效层。亮光不得遮住敌人、岗位按钮或卡牌成本。暂停与设置图标保持现有 UI 语义。

## 8. 资产技术标准

| 项目 | 标准 |
|---|---|
| 格式 | 透明物件 PNG RGBA；地面 PNG RGB／不透明 RGBA；Godot 最近邻过滤，无有损压缩。 |
| 像素网格 | 最终稿按整数像素绘制；硬边，无自动抗锯齿与半透明轮廓。候选图需清理后才可标记 `approved`。 |
| 尺寸 | 地形 36×36；地物 32–96 宽；建筑 64–128 宽；角色 20–36 高。实际占地另由玩法数据定义。 |
| 图集 | 单张优先不超过 1024×1024；同类素材并入共享图集，保留 2 像素隔离边。 |
| 材质／面数／LOD | 纯 2D：无三角面预算和材质槽；缩远时使用简化轮廓／图集变体，不靠任意缩放保留细节。 |
| 命名 | `snake_case`；永久 ID 见素材清单。源图、导出图分目录保存，不覆盖候选版本。 |
| 性能 | 默认镜头中重复树、草、火把须复用纹理；目标维持项目 60 FPS 原型预算。 |

质量门槛：四边平铺检查、1×/0.72×/0.35× 缩略检查、透明像素边缘检查、暗背景和亮卡纸两种背景检查、Godot 4.7 GL Compatibility 导入检查。结构问题不能仅凭单张图看起来完整就通过。

## 9. 正向参考与禁区

正向参考仅为本次用户图片展示的夜色分层、冷暖焦点、聚落与外围威胁的空间关系，以及项目已有 HUD 视觉概念。允许使用中世纪木石、针叶林、羊皮纸和像素画的通用视觉语言。

禁止：照搬参考图的具体建筑排列／徽章／字体／UI 数值；直接切割概念图；混用高清插画与低分辨率像素稿；柔焦、照片纹理、过量粒子、整屏青蓝滤镜；用颜色作为唯一的敌我／合法性提示；在图里加入未经 GDD 确认的天气、地形效果或建筑功能。
