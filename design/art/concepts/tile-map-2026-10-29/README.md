# 指定设计图的瓦片方案预览

2026-10-29。按用户要求先出图，候选未接入游戏。

`map-overview.png`为内置image_gen根据用户设计图新生成的整体效果：保留东北草台/石梯、东南湖岸与外围林缘，去掉中央可建资源树林。实际原生尺寸1962×801，提示词虽要求更大尺寸，不能把返回图称为4K原生。外围树和少量山地景观树仅作构图参考，正式地图仍须独立对象层。

`overview-tiles/`为128像素固定布局分片，`overview-tiles-assembled.png`由112片逐像素重组。它证明切片位置与构图，不代表全图已经补足近景细节，也不是可随意交换的自动地形瓦片库。

近景独立重绘三次均HTTP429，无图稿产物。完整失败提示词另存为`*.failed.prompt.txt`。`hd-cliff-sample.png`因此复用项目已生成的独立草地和崖体原稿合成，保留原生细节、只向下缩采样，不从用户整图裁出最终物件。来源和哈希在`manifest.json`；原生成提示词位于`assets/map_kits/moonlit_v3/source/meadow.prompt.txt`、`cliff.prompt.txt`。

高清样区覆盖144×108世界单位，切为4×3片，每片256像素对应36世界单位，密度7.111，超过4K/960逻辑宽/1.6镜头下的6.4算例条件。`detail-tiles-assembled.png`由12片逐像素重组；相邻固定布局无切片损失，不代表任意瓦片组合接口已通过。样区没有石梯、资源树林或建筑；完整山梯/湖岸高清瓦片仍须继续生产。密度算例不是实际引擎画质/帧率验收。

验证：PNG解码、分片数量、两组像素精确重组、来源哈希、提示词及密度算例通过；既有关卡实例专项17项通过。未更改`src/`、运行资源/碰撞/出生/建筑规则；未重跑GL、长局或全量玩法测试。项目结构及差异检查另见开发进度。

下一步：先评审整体布局和高清样张观感，再按确认方向生产完整地形连接件与高清瓦片，并单独校核石梯通行、建筑贴地和实际缩放效果。本次不继续已被否定的轮廓拉伸方案。
