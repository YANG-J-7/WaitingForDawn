## 方案 B · 山地石垒

蓝黑石板、花岗岩包角与酒红旗。厚重的斜面石墙自下而上层层内收，最终形成带方形垛冠的三层要塞。[五级效果图](stone/town-hall-levels.png)

1. 岩脚厅，矮石板顶覆盖单门石厅。
2. 隘口门楼，在一侧加收分方塔和护坡。
3. 折角堡，两侧斜面石堡托起垛口平台。
4. 阶垒城，双层外墙逐级退台，强化低宽轮廓。
5. 山冠要塞，保留宽厚外垒，中央抬高方形主堡。

## 方案 C · 河谷木城

暖木梁、青灰屋顶、麦穗旗和开放柱廊。由一座横向长屋发展为有双翼和三重宽檐的议城。[五级效果图](timber/town-hall-levels.png)

1. 河谷长厅，单脊长屋配交叉木脊饰。
2. 双脊会馆，侧翼的交叉屋脊伸出遮雨廊。
3. 连廊议厅，两层主厅和连续柱廊拉开正面。
4. 高台木城，左右翼房在宽石台上围住主入口。
5. 千梁议城，主厅升为三重宽檐，青铜色屋面和高暖窗形成远景焦点。
