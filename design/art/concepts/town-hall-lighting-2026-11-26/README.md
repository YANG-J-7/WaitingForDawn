## 各等级的待机设计

| 等级 | 动效 |
| --- | --- |
| 1 · 守夜厅 | 门上短旗轻摆，两盆火焰错开起伏，窗光小幅变化。 |
| 2 · 木石哨所 | 保留门廊动效，增加哨楼上旗尾摆动与哨楼暖窗的独立亮度变化。 |
| 3 · 石门城 | 正门短幡和两座塔旗分别摆动，门楼双火盆照亮近处石阶。 |
| 4 · 守夜要塞 | 门旗与侧堡旗略有相位差，正门灯火错相，侧堡窄窗暖光低幅变化。 |
| 5 · 黎明主堡 | 顶部灯室暖亮，原有双烟管飘淡烟，右侧原有吊灯小幅摆动。 |

旗杆、灯钩、烟口和火盆为动效固定锚点。正式接入候选按实际主城脚点读取地图主光，墙脚暗带贴地，投影背离主光，黎明暖光从东侧接续。
