2026-11-23 静态候选。以第一关现用草地和山脚实景为参考，制作一棵冷青色阔叶树。树体和底座可独立使用，底座由矮草、苔地和零散叶屑构成，边缘留出原地图草地，多棵靠近时可交叠。

## 去底座对照

三款树直接叠在第一关同一块草地上，使用同一组根脚点。现有柔光阔叶树保留外露根系。新绘的低冠青栎与山地冷杉分别试做横展矮冠和高窄针叶剪影，根脚均收短。为呈现各自的高矮，预览树高以现有阔叶为基准，青栎取 0.82 倍、冷杉取 1.07 倍。
