## 随时间转向的树影

2026-11-25。独立光照预览读取地图的真实月光和晨光坐标、颜色和强度。月光沿北缘从西向东走，固定根脚的投影随之转向。临近黎明时，以两路主光的强度平滑过渡，树影缩短和变浅。预览按地表网格遮罩限制投影范围，并保留深色月夜树体。

打开 [光照预览场景](../../../../tools/preview_world_lighting.tscn) 后，拖动时间滑杆可定位，点击“播放光源”按每秒五分钟预览，点击同一按钮可暂停和继续。下面的录屏使用同一处西北林缘镜头，压缩显示 02:10 到 48:00 的实际时间推进。
