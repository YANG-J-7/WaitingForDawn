# Waiting for Dawn 交互模式库

> 更新：2026-09-18
> 状态：HUD视觉实现基线

## 全屏地图叠加 HUD

- 地图是整个逻辑视口的底层内容，镜头缩放和平移不改变 HUD 尺寸。
- 顶部状态栏、底部手牌、商店和上下文面板叠加在地图之上；UI 控件优先接收输入，未被 UI 占用的区域交给地图。
- 地图拖放、建筑点击和镜头操作共享同一屏幕到世界坐标转换。
- 鼠标左键按住拖动或中键拖动平移地图；左键移动不超过6像素并释放才作为建筑单击，拖动不会误开建筑面板。

## 可滚动手牌轨道

- 手牌始终保留独立卡牌实例，不因空间不足叠放或隐藏。
- 当卡牌总宽度超过可用宽度时使用横向滚动；竖向滚动关闭，卡面高度和拖动入口保持稳定。
- 滚动只改变查看位置，不改变库存顺序、星级、合成或拖放数据。
- 左右翻页按钮按当前可视宽度推进或返回，按钮禁用状态随滚动边界实时更新；滚轮/拖动滚动仍可继续使用。

## 战斗中侧边商店

- 商店使用右侧抽屉覆盖地图边缘，打开时地图、战斗、运输、倒计时和底部手牌保持可见。
- 抽屉自身拦截输入，抽屉外地图仍可拖动与缩放；商店打开期间不响应建筑岗位选择，避免上下文面板冲突。
- 六格商品采用2×3布局，同时显示卡名、星级、价格、同名同星持有数量和合成缺口。
- 可购买、金币不足、手牌已满和已售罄必须有明确文字；颜色与灰度只作辅助。
- 刷新区域同时显示当前费用和下一次费用，关闭按钮位于抽屉标题区。

## 地图建筑上下文岗位

- 玩家左键点击有岗位的存活建筑，打开建筑岗位面板并以金色轮廓标识当前目标。
- 面板显示建筑名、当前岗位/容量、空闲人口，并提供不小于 44×44 逻辑像素的减员、增员、自动分配和关闭按钮。
- 点击空地、关闭面板、打开商店、建筑被摧毁、重置或对局结束时取消选择。
- 岗位调整调用权威人口系统；UI只发出增减请求，不直接修改人口或建筑状态。
- 面板依据建筑世界坐标转换为屏幕坐标，优先显示在建筑侧上方；接近边缘时翻转并限制在顶栏与手牌之间。
