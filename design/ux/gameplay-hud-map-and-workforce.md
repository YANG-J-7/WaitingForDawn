# 玩法 HUD、大地图与建筑岗位交互规格

> 更新：2026-10-10
> 适用：Godot 4.7，960×540 逻辑分辨率，Steam 键鼠灰盒
> 状态：已按确认概念图完成程序化视觉布局，并通过自动化与 GL 输入冒烟；正式像素素材和多分辨率人工验收待办

## 目标

1. 1～18张手牌都可访问，不发生卡牌相互遮挡。
2. 地图使用完整逻辑视口，顶栏、手牌和弹窗作为 HUD 叠加层。
3. 人口分配从商店移出，改为点击地图中具体建筑后调整该建筑岗位。

## 状态与流程

```text
战斗地图
  ├─ 点击有岗位建筑 → 选中轮廓 + 建筑岗位面板
  │    ├─ − → 请求减少该建筑1人口
  │    ├─ + → 请求增加该建筑1人口
  │    ├─ 自动分配全部 → 请求恢复全局自动方案
  │    └─ 关闭/点击空地 → 取消选择
  ├─ 打开商店 → 关闭建筑岗位面板，右侧抽屉处理买牌与刷新；地图和手牌继续显示
  └─ 手牌溢出 → 横向滚动查看，仍可拖牌与右键合成
```

## 布局与输入

- `MapDropSurface` 覆盖完整视口；顶栏、手牌、商店及弹窗位于其上方并优先拦截输入。
- 初始镜头缩放为0.72，地图宽度接近全屏；滚轮锚点缩放，按住鼠标左键或中键拖动均可平移。
- 顶部资源、威胁、黎明倒计时、暂停与主城耐久合并为单行状态栏，主城耐久同时使用数值和进度条。
- 手牌栏位于底部并横向铺满视口，标签固定，卡牌区域使用横向 `ScrollContainer`，两侧提供翻页按钮。
- 建筑岗位面板根据所选建筑动态定位并限制在顶栏与手牌之间，显示文字状态，不只依赖选中颜色。
- 战斗商店使用右侧2×3六格抽屉；显示持有数、1星合成缺口、价格和购买状态，刷新栏显示当前与下次费用。
- 左键移动不超过6像素并释放时视为单击建筑；超过阈值则平移地图且不打开岗位面板。单指点击选择岗位目标；拖牌期间不触发建筑选择。
- 减员、增员、自动分配和关闭按钮均不小于44×44逻辑像素。

## 失败与关闭规则

- 岗位已空、已满、无空闲人口或岗位锁定时禁用对应按钮。
- 选中建筑被摧毁或岗位列表刷新后不存在时，面板自动关闭。
- 商店打开、重置、胜利和失败会关闭岗位面板，防止对隐藏世界继续操作。
- 调整失败不改变既有分配，并通过文字提示原因。

## 验收

- 满18张手牌时全部实例仍渲染，横向滚动范围大于可视页宽。
- 地图交互层大小等于960×540逻辑视口；镜头重置为0.72。
- 真实鼠标点击世界建筑能选中对应独立岗位，同类建筑不串联。
- 真实鼠标左键拖动可平移地图，并与建筑单击、手牌拖放互不误触。
- 商店内旧 `JobSection` 不可见，按钮和文案不再称“商店 / 岗位”。
- 商店展开时地图与底部手牌保持可见，六格为2×3布局，抽屉与手牌不重叠。
- 手牌左右翻页按钮可访问溢出卡牌，岗位面板不覆盖底部手牌。
- 建筑岗位按钮尺寸、战斗即时生效、拖牌、镜头和商店回归通过。

## 当前缺口

- 项目尚无正式 `design/accessibility-requirements.md`，本规格只落实现有44×44目标、文字反馈和非纯颜色状态。
- 键盘焦点、手柄导航、屏幕阅读和多分辨率尚未形成项目级承诺，不能据此宣称完整无障碍合规。
- 当前视觉由Godot `StyleBoxFlat`、文字和程序化世界图形组成；概念图中的像素建筑插画、资源图标、正式字体和九宫格面板尚无独立生产素材。

## 2026-10-09 实现补充

资源/状态图标使用独立透明图集；手牌和商品共用羊皮纸九片底板。商品展示建筑插图、持有数与同星合成缺口，底部手牌保留独立实例并显示同名同星×数量；可合成时金边和鼠标提示同时出现，仍使用右键手动合成。人口岗位明细移至悬停提示，顶栏只显示人口总量/容量。设置齿轮提供全屏开关，尚未实现设置持久化。

三个视口960×540、1280×720、1024×768的GL截图已检查；HUD专项59项与真实输入28项通过。独立建筑卡图、字体、键盘/手柄与最终美术批准仍待办，前述“没有资源图标/九宫格素材”属于历史缺口。

## 2026-10-09 黎明胶囊修正与日月转换

根据用户指出的红框差异，黎明区增加独立深蓝圆弧胶囊与蓝灰轮廓；圆弧下缘突出顶栏，左下绿黄弧表示整局有效时间进度。标题为白色，倒计时为金色，月牙使用独立生成的8帧图集。最后5分钟按有效时间从月牙逐渐过渡到太阳，相邻帧淡入，暂停冻结，重开恢复；商店展开继续计时，不增加昼夜战斗机制。

新增30项帧边界、有效计时、暂停、商店、胜利、重置和三视口布局检查通过。全量31组1208项、真实GL日月30项、HUD59项与输入28项通过；截图与加速动画见 `tests/reports/qa-2026-10-09-day-night-clock.md`。

## 2026-10-09 右侧顶栏优化

威胁、主城、暂停和设置收为紧凑连续分区，以蓝灰竖线区分。威胁使用扁平红色符号和红色数值，主城使用简洁白色城堡、白色耐久文字与110×5细绿生命条。暂停/设置按钮44×44，内部18×18白色固定几何符号，不依赖字体彩色字形；常态背景透明，悬停深蓝，焦点蓝灰描边。暂停为双竖条，暂停后为继续三角；设置可在暂停时打开且不自动恢复对局。

真实鼠标和状态更新、多视口边界通过，HUD专项增至78项，全量31组1227项通过。详细证据见 `tests/reports/qa-2026-10-09-right-status.md`。

## 2026-10-10 顶栏高度反馈

按用户要求将顶栏44压至32逻辑像素，约减少27%；计时胶囊同步缩为142×32控件，圆弧外框下缘突出4像素，计时标签待字体最小尺寸更新后重新收紧，避免保留旧字号高度。状态、生命条与18像素控制符号居中；暂停和设置横向点击宽度仍44，高度32，招募高度32。建筑岗位等其他44×44控件保持原规格。

HUD81项、日月30项、真实GL输入28项及三视口检查通过，暂停/继续、商店、计时转换和重开保持真实状态。证据：`tests/reports/qa-2026-10-10-mountain-roads-thin-hud.md`。本次高度由用户反馈确定，不宣称完整无障碍认证。
# 2026-10-14 中间地图视口

地图显示与输入区域从顶栏及突出胶囊的实际下缘到可见手牌实际上缘，宽度随窗口变化。镜头中心、全图倍率、平移限位、拖牌坐标、小地图镜头框统一使用该区域；HUD独立屏幕层。全图等比显示，必要时左右留边，不能拉伸地图或将四边藏在上下栏后。未显示手牌时地图区域延伸到窗口底部。地图对象通过实际裁剪停止绘制到上下栏区域，即使临时隐藏HUD也无地图像素泄漏。

地图四边双细线与角标提示镜头尽头；单位和建筑仅调整视觉尺度，姓名/生命条移到头顶，建筑屋顶也能点击岗位。树林靠近单位保持不透明，仅建造占用时隐藏。三视口、最大倍率、暂停平移与输入证据见2026-10-14地图修复QA。
