# 系统 GDD：自由城墙与战斗商店

> 版本：0.1
> 状态：Godot灰盒通过，微信真机拖放与实时压力待复核
> 权威范围：城墙地图自由落点、多墙阻挡、战斗中六卡购买与刷新

## 目标与游戏支柱

让玩家在怪潮推进过程中即时改变路线防线和卡牌储备。城墙不再绑定单一屏障格；玩家可以把取得的每张城墙牌放到地图空位。战斗商店允许用当前局金币继续购买和刷新，但不会暂停敌人，从而形成“操作商店还是观察战场”的实时压力。

## 玩家动词与核心循环

战斗中打开商店 → 查看六张牌 → 支付金币购买或刷新 → 关闭商店 → 新牌立即进入底部手牌 → 把城墙拖到地图空位 → 路线上的墙阻挡敌人，偏离路线的墙不阻挡 → 城墙被摧毁后敌人寻找下一面前方城墙或主城。

## 规则、状态和转换

- 城墙卡不再使用固定屏障格，改为投放到地图可建造区域内任意空位。
- 一张城墙卡生成一面独立城墙，多张卡可生成多面墙；每面墙独立保存400耐久和20护甲。
- 落点不能超出地图建造区，也不能与城墙、主城、已建建筑、守卫或敌人占位重叠。
- 只有中心距离当前路线不超过40逻辑像素的城墙参与当前单路线阻挡；其他墙保留实体但不隔空影响敌人。
- 敌人优先攻击自己前方横坐标最近的有效路线城墙。墙被摧毁后重新选择下一面墙。
- 战斗阶段显示“战斗商店”按钮；商店打开时怪潮、攻击和资源生产继续运行。
- 每波战斗商店首次打开生成六张牌；同波关闭再打开保留牌面、售罄状态和刷新次数。
- 点击牌支付其金币价格并立即加入最多12张的对局库存；每个展示位每轮只能购买一次。
- 可无限刷新未购买牌，费用为10、15、20、25、30……金币；已购买位置保持售罄且不被替换。
- 购买和刷新都不赠送建造材料；打出建筑时仍需另付材料。

## 公式、单位与算例

刷新费用：`10 + 5 × 本波战斗商店已成功刷新次数`。

墙A位于`(360, 370)`，与路线`y=313`相差57，不参与阻挡；墙B位于`(550, 313)`，位于路线内。野狼经过墙A横坐标时继续前进，抵达墙B攻击范围后才停止攻击墙B。

## 数据与可调参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 地图建造区 | x=80～750，y=140～390 | 避开顶部状态栏、底部手牌和主城 |
| 城墙占位半径 | 28像素 | 与其他单位半径相加判断重叠 |
| 路线阻挡容差 | 40像素 | 当前单路线灰盒值 |
| 商店牌数 | 6 | 与波间商店一致 |
| 普通卡库存上限 | 12 | 与既有库存一致 |
| 首次刷新价 | 10金币 | 每次成功刷新增加5 |

## 输入、反馈与无障碍

- 拖动城墙卡时地图空白区域接受投放；固定屏障格隐藏。
- 非法落点显示明确文本，如“超出建造区”“这里已有单位”，并保留资源和卡牌。
- 战斗商店按钮使用文字而非仅图标；面板标题明确提示“怪潮不会暂停”。
- 卡面显示购买价和建造材料；售罄位置置灰并保留“已购买”文字。
- 关闭商店后立即刷新手牌栏，新购牌可继续拖放。

## 跨系统接口与依赖

- `MapDropSurface`只把卡牌实例ID和地图坐标转换成建造意图，不拥有经济状态。
- `WallManager`拥有城墙集合、墙间占位和生命周期；主场景提供其他实体的占位信息并执行原子扣费。
- `WaveController`查询所有有效城墙并按前方最近原则分配目标。
- `BattleShop`拥有每波牌面、售罄位置、刷新次数和失败原因；`RunCardInventory`拥有购买结果。
- 商店UI只显示控制器状态，不直接改变金币或库存。

## 边界条件与失败恢复

- 非法落点、资源不足、失效卡牌、重复投放或库存变化均不建墙、不扣材料、不消耗卡牌。
- 投放瞬间有敌人占据位置时拒绝建造，不能用城墙直接覆盖敌人。
- 已经越过某面墙的敌人不会被拉回；仍在墙前的敌人可在下一次目标分配时被阻挡。
- 商店金币不足、库存满、售罄重复购买或无可刷新位置时保持全部状态。
- 商店打开期间本波结束时立即关闭，并切换到正常波间结算。
- 打开战斗商店或波间商店时，自动关闭仍停留在画面上的建造资源不足提示，避免弹窗遮挡商店操作。
- 重置清空全部城墙、战斗商店牌面和刷新次数。

## MVP 与延后内容

MVP包含当前单路线矩形建造区、圆形近似占位、多城墙、前方最近阻挡、战斗商店购买/刷新/关闭及文字反馈。延后网格吸附、拖动预览合法色、复杂碰撞形状、寻路绕墙、拆墙、商店慢动作和微信触觉反馈。

## 验收标准

1. 战斗开始后地图投放面开放、固定屏障格隐藏；城墙可放在合法空位且可建造多面。
2. 超界或与任意活跃单位/建筑重叠时原子拒绝，卡牌和材料保持不变并显示原因。
3. 路线外城墙不阻挡；敌人按前方最近顺序攻击路线墙，破墙后继续选择下一目标。
4. 战斗中可打开和关闭六卡商店，打开期间敌人和经济继续运行。
5. 购买精确扣金币并立即加入手牌；售罄、库存满和金币不足保持原状态。
6. 刷新只更换未购买位置，价格按10、15、20……增长；同波重开商店不重置状态。
7. 波次结束自动关闭战斗商店；重置清空多墙和战斗商店。
8. Story-001～013和伤害公式回归继续通过。

## 风险与待验证假设

- 实时商店会分散玩家注意力；真机测试若压力过高，可在打开时启用低倍率慢动作，但不能默认完全暂停。
- 当前直线路径只识别压在线上的墙；正式自由地图需要导航网格决定绕行或堵路合法性。
- 多面400耐久城墙可能显著降低难度，后续怪潮平衡必须按平均购墙数量重新模拟。
