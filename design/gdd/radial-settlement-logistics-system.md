## 目标与游戏支柱

把现有“左侧出怪、右侧主城、固定格建造”的单线灰盒升级为围绕中心主城展开的可读战场。经济建筑必须争夺外围资源点，防御建筑可以自由保护运输线；农民作为真实单位把人口、资源生产和怪物威胁连接起来。

该系统服务三个支柱：地图位置形成取舍、经营与防守共用人口和空间、失败原因可从敌人行进路线直接理解。

## 玩家动词与核心循环

观察资源点 → 选择建筑卡 → 把资源建筑拖到对应资源点或把防御建筑拖到空地 → 分配农民 → 农民往返采集并将资源送回主城 → 从主城花费金币生产新农民 → 怪物从外围接近并攻击途中遇到的农民或建筑 → 调整下一波布局。

## 规则、状态和转换

### 地图与敌人路线

- 主城固定在地图可玩区域中央，灰盒坐标为`(480, 270)`，占位半径56像素。
- 敌人从地图可玩区域四条外围边随机出生；随机序列由`run_id + 波次 + 出生序号`确定，使同一局可复现。
- 每只敌人以自己的出生点到主城中心的直线作为当前进攻路线，不使用导航网格。
- 进入路线走廊的可攻击单位按“从敌人当前位置沿主城方向最先遇到”选择；目标失效后重新扫描路线。
- 城墙、箭塔、兵营、民屋、资源建筑和农民都可成为沿途目标。守卫也按路线几何先后参与拦截，且每人同时只拦截一敌，不因建筑类型产生全图嘲讽。

### 资源地块与建筑

- 2026-09-10开局经济调整：伐木场建造成本由35木材降低为20木材；商店卡价仍为6金币，运输产量与岗位不变。
- 地图灰盒包含树林、农田、金矿脉和石矿脉；每种至少1处，位置由场景数据配置。
- 伐木场只能建在树林，农场只能建在农田，金矿场只能建在金矿脉，石矿场只能建在石矿脉。
- 合法释放后建筑吸附到资源点中心；一个资源点同时只容纳一座对应建筑。
- 箭塔、兵营、城墙和民屋可放在地图任意合法空地，不再依赖固定格位。
- 所有建筑不能覆盖主城、资源点上的既有建筑、其他单位、敌人或地图边界。
- 完整圆形占地必须位于边界内。非资源建筑不能占用资源地块；资源卡使用对应资源点，不与该点自身冲突。

### 民屋与人口

- 民屋是人口建筑，不需要资源地块；建成后增加2人口容量。
- 民屋被摧毁时扣除其容量加成，但人口不会直接死亡；若当前人口超过容量，禁止继续生产农民并标记超额，直到补建民屋或农民损失。
- 开局人口容量为5，并生成5名农民；每名农民占用1人口。

### 农民与运输

- 对局失败或胜利后，所有农民立即停止移动、采集与资源交付，途中货物不再入账；波间仍正常运输，重新开局后恢复。
- 每名农民同一时间处于`空闲`、`前往建筑`、`采集`、`返回主城`或`死亡`状态。
- 分配到资源建筑后，农民从主城前往建筑，采集1秒，携带一次产物返回主城；只有抵达主城时资源才入账。
- 伐木场每趟2木、农场每趟2食、金矿场每趟1金、石矿场每趟2石；每个资源建筑最多2名农民。
- 农民被击杀时，携带资源丢失、当前人口减1、对应岗位自动减少1。
- 调岗优先保留未改变岗位的原农民，携货内容独立于新岗位；换岗不抹掉旧货物，先交付再执行新任务。
- 非资源建筑岗位仍由农民占用：箭塔岗位启用攻击，兵营岗位生成守卫；这些岗位不执行运输。

### 主城生产农民

- 玩家可在对局有效阶段点击主城的“生产农民”按钮。
- 生产1名农民消耗10金币并占用1人口容量；金币不足或人口已满时原子失败并显示原因。
- 生产成功后农民在主城旁出现；战斗锁定岗位期间保持空闲，下一次规划阶段可分配。

## 公式、单位与算例

路线目标判定：

```text
路线方向 d = normalize(主城位置 - 敌人位置)
目标前向距离 t = dot(目标位置 - 敌人位置, d)
目标垂距 p = abs(cross(目标位置 - 敌人位置, d))
合法沿途目标 = t > 0 且 t < 敌人到主城距离 且 p <= 敌人半径 + 目标半径
选择规则 = 合法目标中 t 最小者
```

运输耗时：

```text
单趟时间 = 主城到建筑距离 × 2 / 农民移动速度 + 采集时间
长期产速 = 每趟携带量 × 分配农民数 / 单趟时间
```

算例：伐木场距主城160像素，农民速度80像素/秒，采集1秒。单农民一趟约5秒，抵城时一次增加2木，长期约0.4木/秒；两名农民约0.8木/秒。

## 输入、反馈与无障碍

- 资源点使用不同形状、颜色和文字标签，不能只靠颜色区分。
- 拖动资源卡时，对应资源点高亮；错误资源点显示“该建筑必须建在××上”。
- 空地重叠或越界时保留卡牌和资源，并显示具体原因。
- 农民头顶显示岗位简称和携带资源图标；死亡时显示人口减少反馈。
- 左上主城招募按钮至少44像素高，显示“10金”；相邻资源栏显示人口/容量，悬浮提示解释占用规则。
- 战斗反馈使用不拦截鼠标的短提示；商店打开隐藏战斗短提示与旧建造不足弹窗。岗位列表可横向滚动。

## 跨系统接口与依赖

- `ResourceSite`只保存资源点类型、位置、占位状态和表现，不扣费。
- `SettlementBuilder`负责资源建筑/民屋落点校验和建筑生命周期。
- `MapDropSurface`只发出卡牌实例与地图坐标，不持有建造规则。
- `WaveEconomy`保存岗位分配；`FarmerManager`根据分配驱动实体和运输交付。
- `RunEconomy`负责人口容量、农民数量、金币扣费和资源入账。
- `WaveController`查询统一的可攻击世界目标，不让敌人直接依赖UI或卡牌库存。

## 边界条件与失败恢复

- 错误资源点、已占用资源点、空地重叠、越界、资源不足、失效卡牌或重复释放全部原子失败。
- 商店打开不暂停农民移动、运输或敌人攻击；暂停/切后台时全部冻结。
- 建筑或农民在敌人抵达前失效时，敌人立即重新扫描路线并继续前往主城。
- 运输中的建筑被摧毁时，前往该建筑的农民返回主城；携货农民仍可尝试交付。
- 重置清空建筑、农民、资源点占用、运输货物和随机出生序列。

## 验收标准

1. 主城位于地图中央，敌人可从四条外围边的不同方向出生并直线趋近主城。
2. 敌人只攻击自身进攻路线走廊中首先遇到的建筑或农民；目标摧毁/死亡后继续寻找下一目标或主城。
3. 四类资源建筑只能建在对应资源点，错误地点不扣费、不消耗卡牌。
4. 箭塔、兵营、城墙和民屋可放在合法空地，不能与主城、资源建筑或单位重叠。
5. 石矿场卡可生产石材；民屋建成增加2人口容量。
6. 开局生成5名农民，每名占1人口；岗位分配与地图上的农民实体数量一致。
7. 资源只在携货农民抵达主城时增加，农民途中死亡不会交付货物。
8. 主城可花10金币生产1名农民；金币不足或人口已满时状态不变并提示原因。
9. 重置恢复主城、5名农民和资源点空闲状态；现有卡牌、商店、战斗与波次回归保持通过。

## 风险与待验证假设

- 直线路线比导航寻路轻量，但大量自由建筑可能让目标切换显得突然，需要用路线预览和攻击连线提高可读性。
- 真实运输会显著降低远端资源点效率，需重新平衡卡价、开局资源与单局时长。
- 多方向来敌会削弱固定方向守卫逻辑；守卫拦截需在统一路线接口完成后重做位置判定。
- 5名可攻击农民会提高滚雪球式失败风险，首轮应观察是否需要受击逃跑或波间免费补员。
