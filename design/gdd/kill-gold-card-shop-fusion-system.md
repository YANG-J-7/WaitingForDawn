# 击杀金币、商店抽牌与三卡升星系统

> **状态**：灰盒设计基线
> **作者**：用户与Codex
> **最后更新**：2026-09-16
> **最后验证**：2026-09-16（仅文档一致性，尚未实现）
> **实现支柱**：战斗支撑经营、短期战力与长期构筑取舍、每局从零的肉鸽成长

## 摘要

玩家以4张免费1星卡开始战役，通过击杀野怪获得金币，在持续开放的六格商店购买1星卡或刷新牌面。3张同名同星的手牌可以免费、手动合成一张高一星卡；已建建筑不参与合成。该系统让战斗成果直接转化为家园发展，同时产生“立即部署”与“留牌升星”的取舍。

> **快速参考** — 层级：`核心` · 优先级：`MVP` · 依赖：`60分钟战役、战斗死亡、卡牌库存、建造经济`

## 概述

每局金币从0开始。开局商店提供固定类别结构的6张1星卡，玩家免费选择4张；确认后免费阶段永久结束，此后购买和刷新均消耗本局金币。野怪死亡时按威胁等级自动结算金币，商店持续开放且不暂停战役。玩家可以购买新卡立即建设，也可以保留重复手牌进行三卡升星。金币、卡牌和星级在新开一局时全部清空。

## 玩家体验目标

玩家应感到每一次防守成功都会带来新的发展机会：刚获得的金币既能解决眼前缺口，也能用于追求关键重复牌。升星应像一次明确的构筑成型时刻，但不能让低星铺量失去价值。玩家失败时应能判断是战斗收益不足、刷新过度、买牌方向错误，还是为了合成而延迟部署太久。

## 详细规则

### 开局状态

1. 开局人口为5，人口容量为5。
2. 木材、食物、石材、铁矿初始值均为100；金币初始值为0。
3. 开局商店展示6张1星卡，类别结构暂定为3张经营/资源牌与3张防御/战斗牌。
4. 玩家必须且只能免费选择4张；选择时不消耗金币，卡牌进入手牌。
5. 为避免0金币开局无法获得首杀，4张中至少必须选择1张能够直接或通过岗位造成伤害的牌；界面在条件未满足时禁止确认并说明原因。
6. 确认4张后战役计时与敌人生成开始。免费选择不会在本局再次出现。

“初始资源为100”只适用于木、食、石、铁，不含金币、人口与人口容量。开局卡牌为免费获得，打出建筑仍按该卡的建造材料成本支付；材料成本后续逐卡平衡。

### 击杀金币

新版灰盒中，野怪击杀是金币的标准来源。旧灰盒金矿的被动金币生产在新版原型中停用并等待重新设计，防止安全等待取代战斗和扩张。

| 野怪等级 | 单次击杀金币 | 设计用途 |
|---|---:|---|
| 普通 | 2 | 基础收入；3只普通怪约可购买1张基础牌 |
| 强敌 | 4 | 奖励针对性防守与较高风险目标 |
| 精英 | 8 | 支撑一次重要购买或多次早期刷新 |
| 首领 | 20 | 形成阶段性构筑机会，不直接赠送指定牌 |

规则：

- 奖励在敌人合法死亡事件首次处理时自动入账，不需要拾取。
- 箭塔、守卫、其他友军或后续主动技能造成最后一击，均归入玩家本局金币。
- 逃跑、超时、清理场景、调试删除和新局重置不发金币。
- 每个敌人实例有唯一奖励事务标识；重复死亡回调不能重复发奖。
- 阶段推进不直接提高单只同等级怪物的金币。后期收入通过更多敌人及高等级敌人自然增长，避免金币与战力双重指数膨胀。

### 商店抽牌与刷新

1. 商店有6个槽位，只出售1星卡。
2. 购买成功后卡牌进入手牌，该槽位本阶段标记售罄；购买失败不扣金币、不改变牌面。
3. 刷新只替换未购买槽位，售罄槽位保持不变。
4. 战役每10分钟进入一个威胁阶段；进入新阶段时商店补满6个槽位、清除售罄状态并把刷新次数归零。威胁阶段只是经济与内容节奏单位，不是旧版波次，也不改变60分钟胜利条件。
5. 商店打开时战役、运输、敌人、天气和计时继续运行；手动暂停会冻结全部有效游戏时间。

灰盒卡价：

| 价格带 | 价格 | 用途 |
|---|---:|---|
| 基础牌 | 6金币 | 基础资源、住房、基础防御 |
| 专业牌 | 9金币 | 具有明确路线价值或较强功能的牌 |
| 核心牌 | 12金币 | 能显著改变构筑或承担高价值功能的牌 |

刷新费用按本威胁阶段已经完成的刷新次数计算：

```text
刷新费用 = min(2 + 已完成刷新次数, 6)
```

因此每个10分钟阶段的连续刷新费用为2、3、4、5、6、6……金币。新阶段恢复为2金币。购买不会重置刷新费用，避免通过购买最便宜卡牌反复重置。

商店权重、每张卡所属价格带与解锁条件后续逐卡设计。灰盒阶段不加入稀有度保底、付费卡包、锁牌费用或商店以外的抽牌货币。

### 金币节奏目标

每个10分钟阶段的目标收入为36～54金币，相当于18～27只普通怪，或等威胁的混合敌人。目标支出结构为：

- 购买4～6张基础/专业牌；或
- 购买3～4张牌并刷新1～3次；或
- 围绕某张重复牌投入更多刷新，承担即时战力不足的风险。

整局60分钟的灰盒总金币目标为216～324，不包含未批准的事件奖励。该范围用于测试经济是否能产生多个2星选择和少量3星机会，不是保证每局必定合成指定卡。若自然试玩长期低于或高于目标，优先调整敌人构成与单只奖励，再调整卡价；不同时修改所有参数。

### 三卡升星

1. 所有商店卡和开局免费卡初始为1星。
2. 合成必须由玩家手动确认。
3. 合成材料必须是手牌中3张同名、同星的卡牌实例。
4. 合成消耗这3张卡，生成1张同名且星级加1的手牌；不额外消耗金币或建造材料。
5. 已放置到地图的建筑不参与合成，也不会被手牌合成自动升级。
6. 原型最高3星：3张1星合成1张2星；3张2星合成1张3星。因此1张3星卡需要9张同名1星卡。
7. 达到3星后不能继续合成；正式版最高星级在逐卡设计后复核。
8. 不允许混合星级合成，不自动连锁合成。

手牌容量灰盒值由12提高到18，以容纳开局4张牌和升星储备。手牌已满时不能购买新牌；玩家必须先部署或合成。合成从3张变为1张，因此在满容量时仍允许执行。购买第三张可合成牌时若手牌已经满，仍视为容量不足，不自动合成或临时超容。

星级不会统一套用固定百分比。每张卡后续分别定义：生命、护甲、产能、岗位、范围、攻击、占地、天气/地形互动，以及升星新增或替换的功能。高星卡打出时仍需支付其星级对应的建造成本，该成本也在逐卡设计中明确。

### 战役计时与胜利

- 一局有效游戏时间固定为60分钟。
- 主城在计时归零时仍存活，立即判定胜利，不额外生成第61分钟终战。
- 主城在60分钟前被摧毁，立即失败。
- 主城摧毁与计时归零在同一结算帧发生时，主城摧毁优先，结果为失败。
- 手动暂停和退出游戏不推进计时；商店、建造、手牌与天气界面不自动暂停。
- 新开一局清空金币、材料、人口、建筑、手牌、星级、商店刷新状态、地形占用、天气进度与敌人奖励事务，然后恢复确定的初始状态。

## 状态与转换

```text
新局初始化（5人口，木/食/石/铁各100，金币0）
  → 免费六选四（必须含至少1张伤害牌）
  → 确认后开始60分钟计时
  → 建设/战斗/经营持续并行
      ├─ 野怪死亡 → 首次合法结算金币
      ├─ 商店购买 → 扣金币 → 1星卡入手牌
      ├─ 商店刷新 → 扣金币 → 替换未购槽位
      ├─ 3张同名同星手牌 → 手动合成 → 高一星手牌
      ├─ 每10分钟 → 新威胁阶段 → 商店补满、刷新费归2
      ├─ 主城摧毁 → 失败
      └─ 60:00且主城存活 → 胜利
```

## 公式

### 刷新费用

```text
refresh_cost(r) = min(2 + r, 6)
```

`r`为当前10分钟威胁阶段已经完成的刷新次数，取值从0开始。

### 同星合成需求

```text
合成1张S星卡所需1星同名卡数量 = 3^(S - 1)
```

原型中S∈{1,2,3}，因此需求依次为1、3、9张。

### 阶段金币目标

```text
阶段金币 = Σ（本阶段首次合法结算的敌人等级奖励）
目标范围 = 36～54金币 / 10分钟
```

该目标不要求固定敌人数，只要求混合奖励总量落在可试玩范围附近。

## 边界条件

| 情形 | 处理 |
|---|---|
| 0金币时刷新或买牌 | 原子失败，牌面和刷新计数不变 |
| 同一敌人重复发出死亡信号 | 只发一次金币 |
| 敌人在新局清理期间死亡 | 不发金币 |
| 手牌满时买到可凑三张的牌 | 购买失败；不自动合成、不临时超容 |
| 合成请求包含已建建筑 | 拒绝；只接受手牌实例 |
| 3张卡同名但星级不同 | 拒绝并提示“需要3张同名同星卡” |
| 同时满足多个合成组 | 每次手动选择一组；不自动连锁 |
| 购买扣款后入库失败 | 返还全额金币，商店槽不标记售罄 |
| 59:59暂停 | 计时冻结，恢复后继续 |
| 60:00与主城摧毁同帧 | 判负 |

## 视觉、音频与界面

- 敌人死亡时在死亡位置显示金币数，并同步更新总金币；不能只用飘字，HUD余额必须立即变化。
- 商店卡显示价格、名称、当前拥有的同名同星手牌数量，以及“差几张可合成”。
- 刷新按钮显示当前费用和本阶段下一次费用；阶段切换时提示刷新费已重置。
- 手牌卡显示星级、同名同星数量和合成入口。可合成时使用图标、边框与文字共同提示。
- 合成确认界面展示被消耗的3个实例和产出的高星卡；确认后反馈应在150毫秒内出现。
- 60分钟计时始终可见，最后5分钟增强提示，但不遮挡地图和商店。
- 金币不足、手牌已满、星级不符和材料不足必须给出不同文字原因。

## 验收标准

1. 新局人口为5/5，木、食、石、铁均为100，金币为0，且清空上局卡牌和星级。
2. 开局展示6张1星卡，免费选择恰好4张；未包含伤害牌时不能确认。
3. 开局确认后计时开始，后续买牌与刷新都要求金币，不再出现免费选卡。
4. 普通、强敌、精英和首领首次合法死亡分别增加2、4、8、20金币；重复回调和清理不发奖。
5. 商店持续提供6个1星槽位，价格来自卡牌数据；刷新费用在每个阶段依次为2、3、4、5、6、6……。
6. 每10分钟商店补满并重置刷新费用，不重置金币、手牌、星级、建筑和材料。
7. 3张同名同星手牌可以手动合成高一星卡，不收费；不同名、不同星或包含已建建筑时拒绝。
8. 原型最高3星，3星不能继续合成；合成不重复消费实例，失败不吞卡。
9. 手牌上限18；满手牌允许合成但拒绝购买，扣款后入库失败会全额退款。
10. 主城存活至60:00立即胜利；同帧主城摧毁优先判负，暂停不推进计时。
11. 完成10～15分钟灰盒试玩后，阶段等比例收入落入36～54金币/10分钟附近，并能观察到至少一次“立即部署或留牌合成”的真实选择；这不是完整60分钟平衡结论。

## 开放问题

- 各卡的1～3星属性、功能与建造成本：由后续逐卡设计决定。
- 地形、天气如何改变具体卡牌：由地图与天气GDD决定。
- 金矿卡在新版中的职责：默认停用被动产金，后续可改为其他资源、商贸或风险收益建筑。
- 正式版是否保留3星上限：完成逐卡设计和60分钟试玩后复核。
