# ADR-0001：Godot与微信小游戏技术基线

> 状态：接受  
> 日期：2026-08-26

## 背景

项目是小体量2D像素卡牌塔防，单机运行，使用微信排行榜和激励广告。微信小游戏不是Godot原生一键发布目标，需要版本匹配的WASM模板与平台适配层。

## 决策

- 使用Godot 4.6.3 Standard与GDScript。
- 使用GL Compatibility、960×540横屏逻辑画布和Godot Physics 2D。
- 游戏系统只依赖本地平台接口，微信SDK调用集中在后续适配层。
- 首个灰盒不安装微信导出插件；核心循环可玩后再验证固定版本的社区导出方案。
- 编辑器、导出PCK和微信WASM模板必须使用相同的Godot补丁版本。

## 理由

Godot 4.6.3已经过稳定维护，且现有微信小游戏工具链公开标明测试覆盖Godot 4.3～4.6。相比刚发布的4.7.x，4.6.3更适合作为当前微信导出验证基线。GDScript和兼容渲染可降低包体、依赖与平台桥接复杂度。

## 后果

- 可以立即开发标准Godot 2D工程，不被微信SDK阻塞。
- 微信导出仍是里程碑风险，必须用真机验证WASM、音频、存储、广告和包体。
- 若导出工具只提供其他补丁版本模板，必须成套切换编辑器与模板，并新增迁移ADR，不能混用。
