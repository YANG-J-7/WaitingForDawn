# ADR-0002：Steam 单机平台基线

> 状态：采用；目标操作系统与平台服务范围待细化
> 日期：2026-09-14
> 替代：ADR-0001 的微信平台与引擎版本约束

## 背景与决策

用户明确将项目目标从微信小游戏改为 Steam 单机游戏。已有十波灰盒与桌面鼠标交互；广告和微信排行尚未接入。

- 沿用仓库当前 Godot 4.7 Standard、GDScript、GL Compatibility 和 `res://src/main/main.tscn`。
- 保留 960×540 逻辑画布；正式窗口尺寸、UI 缩放和多分辨率验收待设计。
- Windows 键鼠暂作开发验证基线，其他操作系统和控制器支持另定。
- 核心对局不依赖平台账号、广告或在线服务。未来平台服务通过适配边界接入，战斗规则不直接调用 SDK。
- 暂停微信 WASM 导出与广告、排行桥接；不再因微信模板限制回退引擎版本。
- 本地存档、设置、暂停恢复及桌面导出需要独立任务和验证，不能以已能在编辑器中运行替代。

## 后果与待定项

现有玩法与自动化可继续使用，平台切换本身无需重写当前灰盒。后续导出仍须验证编辑器与导出模板版本匹配、干净环境启动、资源读写和离线运行。

本次未选定 Steam SDK 或第三方插件，也未决定成就、云存档、在线排行、手柄支持、售价与商业模式。正式最低配置、包体与性能预算待桌面测量制定；原微信 8 MB 内容包预算不作为 Steam 发布门槛。

需求依据：[游戏概念](../../design/gdd/game-concept.md)中的平台与单机形态，以及[方向变更影响报告](change-impact-2026-09-14-steam-single-player.md)。
