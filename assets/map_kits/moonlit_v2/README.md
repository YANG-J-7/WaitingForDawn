# 第一关模块化美术包（首版运行候选）

更新：2026-10-28。来源为内置image_gen，源图、手写提示词、参考和哈希见`generation-record.json`及`materials/material-record.json`。

新生成：独立岩面与水面，各1254×1254原生像素，覆盖156×156世界范围，密度约8.038。草地复用1448×1086细草、216×162覆盖；土材质复用独立生成道路资产。材质处理仅闭合32像素边缘，不插值增加细节。参考场景不是运行背景；石阶请求限流无产物，实际石阶用原生几何和生成岩面材质组装。

`py -3 tools/build_modular_materials.py`可确定性重建材质和mipmap导入设置，再用Godot导入。项目当前忽略PNG导入配置，干净克隆需先运行此工具；不能把缺少mipmap的默认导入当作已验证输出。

关卡装配在`src/levels/level_001.tscn`，零件场景在`src/levels/modules/`，局部语义数据及控制图在`assets/levels/level_001/`。编辑组件位置须36单位对齐。当前已支持组件平移；形状编辑仍需同步语义数据与控制图，通用可视化地形编辑器、自动接缝/端口工具尚未完成。迁移工具读取旧关卡只用于初次迁移，不应覆盖后续手工编辑。

当前山体保留为本关大型地形组件，尚未细拆成计划中的全部崖段/凸凹角库。岸缘为共享材质控制带，树林和主城底座复用已有素材。素材包仍有明显重复岩纹，整体构图/风格不是最终美术验收。完整十二类变体、风动、动态避让、性能预算和自然长局继续待办。
