## 文件与使用

- `beach-overlay.png`：1070×325、RGBA、已烘焙冷色沙滩与草缘alpha的静态透明叠层；样区放置原点(0,180)。PNG已去预乘，直接叠在现有底草上；不包含另画的草地，也不包含动态泡沫。
- `sand.png`：1646×500原生裁切/接边材质，配合`grass-contact.png`与材质可调整草沙过渡和湿沙；左右边RGBA相同，上下透明。
- `foam.png`：1646×210独立浪花纹理；左右边RGBA相同，不是六帧换图。`beach_foam.gdshader`连续推进/退回两道错峰浪花并消散，4秒单浪、12秒全层循环，导出60fps。
- `beach-grass-composite.png`：1070×720静态合成贴图，草地采样相位固定在世界原点(0,0)。适合看图/对应原点使用，不应任意平移后宣称与整张地图草地仍逐像素一致。
- `preview.png`为实际1920×720 GL合成效果；原稿、提示词、来源及SHA256见manifest。ZIP按项目相对路径打包，含运行脚本和草/水依赖，可解压到独立Godot测试项目相同路径。

Godot预览入口`res://tools/preview_beach.tscn`，F6运行，按钮支持暂停/复位。正式`src/main/main.tscn`保持原岩岸。本样区用与地图相同的grass_map.gdshader及1254草图/360世界单位密度，所有沙滩分片以同一坐标框架采样；交界陆侧沙图alpha归零，直接露出原草地。独立贴图移动到正式地图其他位置时，优先让原地图底草继续绘制，只叠透明沙滩；完整集成需使用地图世界坐标设置材质，不能另贴一块固定相位合成草图。

草缘用现有草叶纹理打散窄过渡，避免宽灰雾；湿沙、浅水、泡沫和原湖面纹理独立。顶点和沙地图纹理不移动，运动只在浪花与湿沙/水面层中。连续秒驱动，不在每张关键帧处重复停顿，也不使用不受暂停控制的TIME。
