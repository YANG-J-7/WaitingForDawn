# 草地装饰贴图组三款

日期：2026-11-11。以用户已认可的ASSET-0016静态草地为底图，内置image_gen分别编辑小碎石、大石头、野草与花三款候选。原草地不覆盖；四张交付图均为1254×1254静态PNG，经共同边缘装配后配套使用，生成原稿保持在`source/`。

| 文件 | 内容 |

| `small-stones.png` | 松散半埋蓝灰小碎石与短草 |

三次编辑直接使用同一纯草地，新增物件不触边，保持草叶尺度、夜色和左上光向。用户三张附件保存在`references/`，完整手写提示词与原始生成图在`source/`。来源、尺寸和哈希见`manifest.json`。混铺时使用本目录`grass.png`，不要混入旧目录未经闭边的原稿。

## 共同边缘装配

初次直接拼原稿时发现细草截断，生成提示并未保证边缘像素一致。为此使用Godot离线静态材质，把原草地的偏移采样在边缘连续过渡，并让四款共用同一周期底草；装饰款仅在外围4%～17%宽度退回共同底草，中部石头和花草不被切边。首末像素中心对齐同一周期端点。不绘制新草叶或石头，不量化、不放大、不改变全图色调，允许过渡带存在轻微柔化。

装配命令（需要真实GL，不能加`--headless`）：`Godot --path . --rendering-method gl_compatibility --script res://tools/assemble_grass_variant_tiles.gd`。这是项目内离线工具，不是游戏导出运行器。

## 拼铺审阅

- `contact-sheet.png`：从左到右为纯草地、小碎石、大石头、野草与花，缩略图标题仅供审阅。
- `mixed-tiling-full.png`：5016×5016原生4×4混排，直接拼接四款实际交付图，检查图不额外混合接边。
- `mixed-tiling-preview.png`：上述混排的1600×1600缩略图。
- `four-corner-native.png`：四块交点的512×512原尺寸局部。
- `validation.json`：PNG、尺寸、源图一致性、提示词、引用和16种有向水平／垂直接边的辅助数据。

完成Godot装配后，用`tools/build_grass_variant_preview.py`重建审阅图与元数据。该脚本只校验交付图、装配和缩小审阅图、计算指标，不修改交付贴图。

验证67项通过：包括四款1254×1254有效图像、来源和提示词，以及16种有向组合共32组水平／垂直接边。边界每通道最大差不超过1/255（GPU八位量化容差）；已目检最终4×4混排及原尺寸四角交点，原先硬接线已消除。存在固定草簇重复和过渡带轻微柔化，最终观感仍待用户复核。后续正式接入时，大石头的通行占用、遮挡与排序应独立定义；本素材组没有批准碰撞或采矿规则。

本轮只交付贴图与审阅图，现有F6纯草地预览和正式第一关保持原入口；不重新启用草地动画。
