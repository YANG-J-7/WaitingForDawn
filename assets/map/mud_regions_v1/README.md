## 与草地衔接

草地基准为`assets/map/grass_variants_v1/grass.png`，从中央原生裁切512×512保持叶片尺度，避免把1254原稿压进每一小块而使外围草过细。Godot离线材质只处理整片3×2区域的最外圈：外侧4%～22%单图宽度退回共同底草，内部七处接边不加草框、不重复羽化。配套草地自身采用偏移采样闭边，每款附`grass-companion.png`作为相同采样与密度的外围草地，`surrounded-preview.png`展示实际周围拼接。沿用青蓝、灰青绿夜色与略俯视笔触；草边有轻微采样柔化，最终观感仍需用户复核。

## 来源与处理

内置image_gen依据同一草地和用户泥地参考，分别生成三张无分隔母图。原始PNG、完整手写提示词在`source/`，用户附件在`references/`。提示词目标3072×2048，工具实际原生返回1536×1024，因此交付按真实原生切成512×512，未插值放大。生成原稿保持，装配结果另存`assembled.png`。

重建顺序：用Godot真实GL执行`res://tools/assemble_mud_regions.gd`装配整片外圈，再执行`tools/build_mud_region_bundle.py`精确切片、校验、重组、生成审阅图与ZIP。脚本不绘制新的泥土、草叶或石头。

## 验证与审阅

真实GL装配三款通过，无脚本或渲染错误。101项检查通过：18张有效且不同的512×512图块，六图重组与装配母图逐像素一致，三款共21处内部切线0装配差异，30段外边与配套草地每通道最大差不超过1/255。内部两块的末列和首列是自然相邻像素，不要求相同；0差异指重组没有引入额外接缝。
