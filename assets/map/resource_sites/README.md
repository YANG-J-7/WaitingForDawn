# 独立资源点素材

| 文件 | 用途 | 尺寸 | 透明 |
|---|---|---:|---|
| `forest_resource.png` | 密集树林，供伐木场定位 | 512×420 | 是 |
| `stone_deposit.png` | 石矿，供石矿场定位 | 384×240 | 是 |
| `iron_deposit.png` | 铁矿，供铁矿场定位 | 384×220 | 是 |

`source/` 保存石矿、铁矿及历史树林生成原稿；各 `.prompt.txt` 记录生成要求。当前树林直接复用边界松树素材，由构建脚本组合为15棵实心密集树丛，中心也有树木。伐木场仍落在资源点中心，建成后隐藏树丛视觉。三项素材不包含地图底图，可重复摆放。实际显示尺寸、八处位置、资源点半径和卡牌 ID 见 `../moonlit_resource_map_16x9_sites.json`。PNG 的完整画布不作为碰撞形状，建造落点以资源点中心和半径为准。

当前主场景从JSON加载4处树林、2处石矿和2处铁矿；对应三类建筑均已接入。树林在伐木场占用时隐藏，建筑销毁或重置后恢复。矿点通行、精细湖岸和绕障运输仍待后续设计。
