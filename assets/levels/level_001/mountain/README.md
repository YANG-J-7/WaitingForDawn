## 规则与重建

运行数据在module.json。tools/build_level_mountain.py读取已确认原稿，编译2609个山体格和311个路径/梯格；9段石梯按新图逐段标注，不复用旧八梯/S6坐标。手画中心线只作为意图，蓝色岩面覆盖率阻止中心线直接穿崖，再沿地面编译四连通路线；湖水优先。routes-debug.png是调试标注图，不进入运行绘制。

离路草台沿用mountain_grass禁行/可建规则，硬岩禁行禁建，梯段禁建。当前共用高度标签0，通过岩面/离路格隔离通路；没有制作连续高度场或逐层建造校验。石梯肩部和草岩边界仍受36格精度限制，尚未做自然单位逐梯走位和完整山区经济试玩，不能把网格路径结果当作完整玩法验收。

重建命令：uv run --with pillow --with numpy python tools/build_level_mountain.py。原稿不覆盖，build-qc.json记录原生尺寸、来源/输出SHA256和格数。本机导入启用Linear+mipmap；PNG导入配置按现有仓库规则仅留本地，首次导入的其他电脑需核对mipmap。
