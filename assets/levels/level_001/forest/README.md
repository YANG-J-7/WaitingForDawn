# 第一关外围树林与岩石

2026-11-24。以用户提供的全图为构图参照，西北、西缘和西南较密，北缘和南缘之间留草地缺口，往山脚用三五株混排的小林丛收尾。中央平原和石梯入口留出视线及通路。岩块以两三块高矮搭配为主，放在林缘与山脚。

- `layout.json` 使用第一关世界坐标。每个林丛条目记录中心、椭圆的两个半径和株数。岩块条目记录成组中心和数量。种子固定为 20261124，在草地范围内散布并筛掉太近的树根。
- 独立树体来自[确认稿](../../../../design/art/concepts/tree-2026-11-23/README.md#参照设计图调整落地)。第一关用到 102 棵低冠青栎、95 棵高冠阔叶，岩块复用 [ASSET-0020](../../../props/rocks_transparent_v1/README.md) 三款，共 61 块。
- 主图和小地图共用布局。树体按根脚 Y 值排序，根尖淡出露出原地草色，树石落点都加轻微接触暗影。所有树石属于视觉装饰，尚无碰撞、采集、摇晃与落叶行为。
