## 来源与重建

复用ASSET-0025已认可的内置image_gen沙/泡沫原画，不用代码生成原画。运行材质为src/gameplay/art/map_beach.gdshader；tools/build_level_beach.py仅编译曲岸采样坐标。上段参考现有山体alpha的外侧山脚，下段使用原湖泊岸线控制点，曲线向画幅上下延长后按世界边界裁切。

whole_coast-field.png将沿岸弧长和有符号距离分别用16位双通道编码，四世界单位一采样，纹理必须无损、关闭mipmap、关闭alpha边缘修复、关闭预乘，不作sRGB色彩解释。弧长统一映射生成沙与泡沫，草缘仅以alpha露出原底草；浪花连续涌入/退回/消散，湿沙共用湖泊12秒时钟，不加载大量逐帧PNG。小地图固定零时刻。

重建：先按需重建山体/湖泊与mountain/contact，再运行tools/build_level_beach.py，Godot导入。contact构建器会保留beach_layout引用。全岸模式replace_all_rock_shore=true，沿岸弧长编码范围16384，旧两湾控制图不再运行使用。build-qc.json记录源纹理和水域规则文件SHA256。
