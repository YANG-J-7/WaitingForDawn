# 第一关设计图湖泊接入 / ASSET-0023

2026-11-13，已接入`res://src/main/main.tscn`。第一关仍为环境制图模式。湖泊位于东北侧、东侧及东南，保留中央草地，两处内凹湾和伸入湖面的岩岬参考用户设计图排布；山体、石梯、树林不在本轮恢复范围。

ASSET-0019周期闭边水面用于正式湖面；ASSET-0021原六关键帧水花在10个固定样点按60Hz播放。三款ASSET-0019/0022水平岸段只支持同向横接，无法直接沿设计图回头湾铺设：本轮以它们作为材质/形态参考，用内置image_gen生成东北转向和南部双湾两份定向适配图。没有直接裁切概念图作为最终湖岸，也没有旋转整张水平岸图。

原生东北图1207×1303，南湾图1774×887；原稿、手写提示词、设计图局部参考、仅几何用途的布局线稿、去底记录和来源哈希保留本目录。东北图上/右端、南湾上端属于连续地图接口，源图触边为人工复核的有意延续；处理器仍拒绝输出触边、空帧或粘贴裁切。manifest记录内置生成来源。运行`shore-overlay.png`3556×2880为关卡装配坐标输出，不称原生高分辨率生成或全层4K细节。

`tools/build_level_lake.py`只进行去底、色边清理、alpha过渡、布局装配和控制/规则编译。`layout.json`控制层原点(3500,0)、10处水花及12秒/60fps时钟；`module.json`水域多边形是画面水域遮罩和地形编译的共同来源，保守地将任意相交的36格记为水域，共2741格禁行禁建。相邻陆地沿用现有shore通行代价及禁建规则。源图片矩形不作为碰撞。

`shore-overlay.png`原画UV保持固定；`shore-water-only.png`仅允许纯水处的反射亮度变化。`water-control.png`R为水域覆盖、G为静态岸石保护、B为近岸深度权重。深水、浅水、月光、水花共享12秒时钟；水花还受水域及静态石头保护裁切。角色暂停、制图暂停按钮与重开均可冻结/复位时钟。小地图复用同一组件/布局，使用固定静态帧且不创建水花，避免微型闪烁。

验证和实际截图见`design/levels/lake-integration-20261113/README.md`。已完成模型/网格/寻路、主图/小地图、7处岩石×12时刻、10处水花、暂停/恢复/重开、12秒回环、不同画幅及60fps视频。最终造型、岸边导航自然度仍待用户复核；这是当前第一关专用适配布局，不是通用闭合岸线编辑器。新增地表沿用现阶段原画色彩，未接动态昼夜主光；4K仅验证覆盖和截图，不证明原生细节或稳定帧率。
