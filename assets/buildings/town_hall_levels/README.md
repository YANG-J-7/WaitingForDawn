# 红瓦主城运行外观

2026-11-27。一级守夜厅供第一关正式开局拖牌落位。一至五级共用主城表现组件，可在 [地图光照预览](../../../tools/preview_world_lighting.tscn) 的「主城外观」下拉中切换。预览复用第一关地图、镜头、移动月光和东侧晨光。

每个 `level_*.tres` 包含主体纹理、显示宽度、贴图脚点、墙基落地轮廓，以及台阶、墙体、屋脊、塔楼等体块的投影坐标。坐标以原画像素为单位。运行时按当前城址的主光位置投射，沿地图地表遮罩裁掉水面上的阴影。

二至五级各自的 `faces.png` 记录屋瓦和墙面朝向、东西两侧瓦脊与檐口的反光位置。各级的 `hearth.png` 记录原画固定高光的校正范围、暖窗与局部灯火权重。主体来自用户确认的红瓦设计板，来源见 [二至五级光影预览记录](../../../design/art/concepts/town-hall-levels-lighting-2026-11-27/README.md)。一级沿用 [分层守夜厅原画](../town_hall_level_1/README.md)，使用确认后的左檐受光和四帧双火盆素材。

二至五级的显示尺寸沿用评审比例，正式占地及升级条件待设计。
