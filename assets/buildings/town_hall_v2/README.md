# 主城分层素材 v2

2026-10-23，依据用户确认设计制作并接入；状态为运行候选，最终审美待复核。

`body.png`为独立生成、去背景并裁边后的958×1043建筑，显示为180×176世界像素。屋顶旗杆保留，旗布、火焰和薄烟独立；主体脚点为底部中心。两张阴影由主体alpha确定性投影/压缩得到，位于地表之上、单位之下，不增加占地。

`flag/`、`flame/`、`smoke/`分别含四个256×256透明帧及局部GIF；对应原稿均是2×2网格。帧之间共用缩放，只平移根部。旗帜0.23秒/帧，火焰0.12秒/帧且两火把错相，薄烟0.65秒/帧交叉淡入、透明度0.32；独立动画GIF的时间仅供素材检查，游戏实景GIF以实际组件为准。烟形面积变化为特效设计，不适用人形体积CV门槛。

`source/`保存内置image_gen四张原稿、四份完整提示词、原生成路径与参考记录。`processed/`保存generate2dsprite严格QC、透明图集和处理元数据。`manifest.json`记录原稿哈希、建筑附着点、平移和QC信息。`tools/build_town_hall.py`完成后处理重建；`tools/check_town_hall_assets.py`复核确定性、透明边缘及帧差异。

本素材包由TownHallVisual组件读取，与主城4×4逻辑占地、资源交付及战斗分离。暂停/胜负冻结、重开复位，摧毁隐藏附着特效。窗光仅作用于暖色窗芯，非整栋建筑变亮。
