# 主城地面底座

2026-10-26，运行候选，已接入`TownHallVisual`，最终观感待用户复核。

独立内置image_gen原稿，以用户确认的场景设计为风格参考、主城主体为脚点与视角参考，仅生成一块地面贴花。没有从设计场景中截取地面，也没有替换建筑主体或旗帜/火焰/薄烟动画。

- `source/`：1816×866生成原稿、完整提示词、原生成路径、参考哈希与生成记录。
- `processed/`：generate2dsprite的单图去底结果、原稿副本及处理元数据。单图处理不宣称通过多帧严格QC，源边界及透明结果由专项检查验证。
- `ground-base.png`：1280×792 RGBA，矮碎石、半埋旧石板、压实土和渐疏草缘；外缘使用透明度过渡。
- `manifest.json`：源文件哈希、裁边、等比缩放、固定夜景调色及世界矩形`(-166,-120,320,198)`。

`tools/build_town_hall_base.py`只做确定性裁边/缩放/调色/alpha处理；`tools/check_town_hall_base.py`验证重建一致、四边透明、来源、草缘半透明、无紫边和台阶附近地表不空。原稿背景存在轻微洋红色差，去底和边缘检查使用色域判断。

运行使用Linear过滤，作为独立地面层的首个Sprite绘制，在主城两层阴影与人物下方，不参与输入、占格、碰撞或导航。重开复用同一节点，退出场景自动释放。实际GL截图、相邻箭塔建造与范围外像素检查见`tests/reports/qa-2026-10-26-town-hall-base.md`。

用户红框指出左塔后侧缺少连续草缘，新增独立素材。`source/rear-left.generation-record.json`保存两次生成记录及参考哈希；斜向首稿只保留作v2参考，运行采用`processed-rear-left-v2/clean.png`。后侧层世界矩形(-144,-110,110,125)，门前层仍保持原世界脚点与比例，二者透明合成后导出。三处草缘邻域检查允许草叶之间的自然空隙，不要求草带每个像素不透明。
