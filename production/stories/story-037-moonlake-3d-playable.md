# Story-037 · 月湖山谷 3D 样区玩法接入

状态：P1 样区已交付，专项验证通过。更新于 2026-11-07。

依据：[P0 样区](story-036-moonlake-3d-graybox.md)、[3D 地图方案](../../docs/architecture/moonlake-3d-map-and-lighting-development.md)、[网格 GDD](../../design/gdd/grid-map-rendering-system.md)、[ADR-0002](../../docs/architecture/adr-0002-steam-single-player-baseline.md)。

## 验收

1. 在独立场景拖动真实卡牌时，鼠标射线只取第一个地表交点。将 3D 水平坐标映射回 36 世界单位网格，使用完整占地和等高表面校验，显示预览。
2. 合法 1×1 和 2×2 建筑复用原库存、资源、建造和网格占用流程。水面、崖壁、石梯、占用、跨层、越界、资源不足及错误资源点均拒绝，失败保留牌和材料。4×4 校验覆盖整块占地。
3. 样区农民沿原寻路双向通过 S6，脚点随格高度变化。上台农场可安排农民采集并将食物运回。
4. 样区小地图标注地形、建筑与农民，可点选定位近景。Godot 无头、实际 GL 输入、正式入口冒烟、结构和差异格式检查通过。

沿用 Story-036 的几何样区，材质、水面、树林与光照对照由 [Story-038](story-038-moonlake-3d-art-lighting.md) 承接。

## 体验与实现

- 用 Godot 打开 [P1 样区](../../tools/preview_moonlake_3d_playable.tscn)，按 F6。将农场拖到上方青框，让农民往返采集。右上按钮可单独演示 S6 双向往返，右下小地图点击定位近景。1、2、3 切换镜头，G 开关格线。
- 松手与预览共用视口坐标，物理帧内以首个射线命中作为落点。3D 的 X/Z 加样区原点并乘 36 回到第一关世界坐标。建筑按整块等高占地贴地，农民按当前格的真实灰盒表面高度显示。
- 样区复用原卡牌库存、卡价、建造实体、资源和寻路，使用一名农民及四张测试用起始卡。范围内没有现有资源点，伐木场用于验证错误位置。4×4 验证占地接口，现场可拖卡牌为 1×1 和 2×2。

## 验证证据

| 验收 | 结果 |
|---|---|
| 射线与预览 | 通过。GL 实际输入路径下绿色预览与落成对齐，水面显示红色，近景前方崖面拒绝落点。 |
| 建造与事务 | 通过。农场、民屋、城墙复用既有材料与网格。水域、岩壁、石梯、单位、已有建筑、材料不足及错误资源点均保牌保材料。跨高差和越界占地拒绝。 |
| 农民与运输 | 通过。双向经过 S6，多级踏面脚点与当前格表面一致。阻挡目标后停步，解除后可继续。山台农场运输实测食物从 100 增至 102。 |
| 小地图和运行 | 通过。实际点击定位近景。P1 无头 36 项，1280×720 与 1024×768 窗口 GL 各 57 项。P0 无头复测 433 项，正式主场景无头启动、项目结构和差异格式检查通过。 |

本地日志见 `.codex-temp/moonlake-p1-headless.log` 与 `.codex-temp/moonlake-p1-gl-1280x720.log`、`.codex-temp/moonlake-p1-gl-1024x768.log`。两窗口的预览、建造结果截图已复核。全量历史回归本轮未重跑。样区使用逐格踏面高度和 2D 立绘，正式模型、材质、光影及压力测试进入 P2。
