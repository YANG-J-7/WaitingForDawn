# Story-028：建立80×45地图网格与建筑占格

> 状态：灰盒实现完成；单位寻路与地形美术按后续Story推进
> 更新：2026-09-24

## 目标

在现有2880×1620资源地图上建立36世界像素、80×45格的权威玩法网格，并让地图建筑使用统一坐标换算、吸附、地形校验和静态占用规则。

## 本阶段范围

1. 新增独立的`GridMapModel`，保存地形、资源格和静态占用。
2. 提供世界坐标与格坐标换算，以及1×1、2×2、4×4占地吸附。
3. 湖水格不可建；空闲资源格只允许对应资源建筑占用。
4. 城墙、箭塔使用1×1；资源建筑、农场、民屋、兵营使用2×2；主城使用4×4。
5. 建筑拖动时显示网格、合法性和实际占地矩形。
6. 建筑建成、摧毁和重置时同步写入或释放静态占用。

## 本阶段范围外

- 敌人、农民、守卫的`AStarGrid2D`寻路。
- 草地、湖岸和崖壁的TileMapLayer美术重制。
- 动态单位格预约与局部避让。

## 验收标准

1. 地图固定为80×45格，每格36世界像素。
2. 世界坐标与格中心换算结果稳定，建筑落点按占地尺寸吸附。
3. 多格建筑完整写入占用，重叠、越界、湖水和错误资源格均拒绝。
4. 建筑销毁或重置后释放全部占用格。
5. 建造拖动期间显示网格和1×1或2×2占地反馈，结束拖动后隐藏。
6. 网格专项、地图建造相关测试、项目结构和差异格式检查通过。

## 实现结果

- 新增`GridMapModel`，地图固定为36世界像素、80×45格，保存草地、湖水、资源格和静态占用。
- 主城对齐4×4网格；箭塔、城墙使用1×1；兵营、民屋、农场及资源建筑使用2×2。
- 资源点由JSON载入后对齐2×2格中心，并将对应格登记为资源专用地形。
- 所有玩家地图建造入口统一先吸附、再检查地形与静态占用；建筑销毁及对局重置会释放占用。
- 拖动建筑卡时绘制80×45网格，并以矩形显示建筑的实际占地及合法状态。
