# Story-039 · 月湖山谷第一关 3D 迁移

**状态** P3 整关运行候选已接入。首次构图已移到关卡加载阶段，批量路径预算和人工评审待收口。更新于 2026-11-07。

依据：[3D 地图 P3](../../docs/architecture/moonlake-3d-map-and-lighting-development.md#5-实施顺序与阶段出口)、[P2 光影样区](story-038-moonlake-3d-art-lighting.md)、[第一关地图](story-033-modular-level-map.md)、[60 分钟局制](story-025-sixty-minute-city-defense.md)。

## 验收

1. 独立整关入口覆盖 196×80 格，复用第一关 2D 权威数据，校核八资源、四出生点、八石梯及采运连通性。
2. 既有对局通过同一套系统运行，3D 负责显示与拾取。真实输入可开局、拖牌建造、点击岗位和小地图定位；镜头总览、近景和回城可用。
3. 首个地表拾取与脚点高度一致，水域、崖面和跨高差落点拒绝，正式 2D 入口提供对照。
4. 记录整关帧时间、路径压力、长局与剩余验收，默认入口切换另行决定。

## 预览与实现

- 在 Godot 打开 [整关 3D 候选](../../tools/preview_moonlake_3d_level.tscn)，按 F6，再点开始对局。滚轮缩放，左键或中键平移，M 切换总览，Home 回城，小地图可定位。F5 为正式 2D 对照。
- 平原、山区和湖岸使用原关卡地形编译结果，按 28 块地表网格绘制。水面覆盖原水域，远景收敛高频水纹。外围 124 株树复用原摆放，以 3D 共享网格批绘。原矿点、主城、建筑和单位使用脚点对齐的立绘。
- 镜头向原格高度场取第一个地表交点，崖面拦截后方落点，预览与拖放执行同高占地校验。原主场景继续负责选卡、卡牌消费、占地、岗位、经济、战斗、对局计时和结算。3D 主光读取真实有效时间，最后 5 分钟进入黎明，实时阴影采用全关档。

## 渲染测量

Windows，Godot 4.7 GL Compatibility，i7-12700 与 RTX 3060 Ti。关闭 VSync，55 帧预热，150 帧采样。场景含 50 名实际农民实例，定格后测量渲染。有效视口分别为 1920×1080 和 3840×2160。

| 视角 | 1080p 帧间 P95 / P99 / 峰值（ms） | 4K 帧间 P95 / P99 / 峰值（ms） |
|---|---:|---:|
| 整关总览 | 2.339 / 2.523 / 2.825 | 2.290 / 2.439 / 2.473 |
| 主城近景 | 2.406 / 2.468 / 2.672 | 2.448 / 2.539 / 2.562 |
| S6 近景 | 2.242 / 2.653 / 3.095 | 2.110 / 2.243 / 2.244 |

当前地形为逐格高度，岩壁、岸线和林缘的最终观感仍待评审。候选继承原主场景，启动时也构建原 2D 表现资源，显存预算待实测。正式切换前优先处理整关寻路峰值，再复核实际操作手感、人工长局与阴影档位。

## 2026-11-07 寻路收口

首次构图一次生成每条无向边。对角边继续要求方格四条正交边全通。场景在登记主城和资源点后预热寻路图，建造、释放或层级变化只重连受影响邻域。运输查询共享目标外围格，并跳过距离下界已经超过当前最优代价的候选。

| 整关同机对照 | 旧寻路器 | 优化后 |
|---|---:|---:|
| 新建寻路器首次查询 | 872.560 ms | 29.679 ms |
| 同批 50 条运输路径 | 50.248 ms | 23.436 ms |

预热后的主场景首条未缓存查询为 0.713 ms，单格占用后的下一条路线为 0.776 ms。50 条路径逐点一致，加权代价和交互停距一致。165 项专项通过，覆盖全图相邻边、封路和破障参考、释放恢复、代价变化及两列网格。

P3 无头 78 项、3D GL 77 项、2D GL 17 项、P2/P1/P0 无头 33/36/433 项和项目检查通过。优化后固定 60 Hz 无渲染回放守至 60:00，主城剩 334/600，胜利及重开通过。两次回放的对局随机标识不同。日志见 `.codex-temp/moonlake-path-*`。

单帧集中处理 50 条路径仍超出 16.67 ms，整关人工体验和正式切换继续待验。
