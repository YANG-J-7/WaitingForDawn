# Story-018：第5～10波与后期压力曲线

> 状态：灰盒自动化验收通过（2026-09-11；人工试玩与真实胜率待验）
> 依赖：Story-015～017灰盒验收已通过；用户于2026-09-11明确要求直接开发，人工试玩保留待验。
> GDD：`design/gdd/single-night-wave-system.md`

## 目标

让第4波之后的流程继续到第10波胜利，不在本故事同时接入怪物王、彩蛋、广告或排行。

## 验收标准

1. 添加第5～10波可加载的怪潮数据。
2. 第1～5波普通怪威胁预算倍率1.0；第6～10波依次为1.1、1.21、1.331、1.4641、1.61051。
3. 10%增长只作用威胁预算，不再同时倍增生命和伤害；整数编成需记录取整方式。
4. 第5～10波购买商店、刷新、手牌保留、农民岗位和运输可持续工作。
5. 每波只结算一次，第10波清场进入胜利，不再显示第11波商店。
6. 任意波主城摧毁立即失败；重置恢复第一波和5名农民。
7. 覆盖倍率、波次衔接、胜负、重复结算，运行全套回归；真实胜率与自动化流程测试分开记录。

## 验证

新增 `tests/test_ten_wave_flow.tscn`，177项定点断言通过；覆盖主场景从第1波到第10波的真实死亡信号推进、后期商店与运输、通关和失败、重复结算与重置。受控清怪与测试资源补充仅用于功能验证，不代表玩家可通关或已达成10%胜率。

| 验收项 | 结果与证据 |
|---|---|
| 1 数据 | 通过：主场景加载十份有效定义；第5～10波新增资源，拒绝越界、零数量和零间隔。 |
| 2 倍率 | 通过：逐波核对1.0与1.1～1.61051。 |
| 3 取整及属性 | 通过：第5～10波基础数量5、单只威胁5；预算先四舍五入再取最近整数只数，实际为5、6、6、7、7、8只。逐波验证生成敌人生命55、伤害8。 |
| 4 经营 | 通过：后续商店、购买、刷新、手牌保留、岗位与运输交付、战斗商店开关；原有商店回归保持通过。 |
| 5 结算胜利 | 通过：十波各结算一次；第10波实际清场胜利且关闭商店。GL截图验证胜利标题和重开按钮可见。 |
| 6 失败重置 | 通过：第5～10波主城归零立即失败；同帧清场与主城摧毁判负；重置隔离迟到回调、清空本局记录，新局恢复5人。 |
| 7 回归与胜率 | 自动化通过；人工试玩、自然战斗胜率和微信真机未验证。 |
