# Waiting for Dawn（等待黎明）

一款面向Steam的单机2D像素家园经营与生存肉鸽游戏。新版一局60分钟、每局从零开始，守满60分钟且主城存活即胜利；击杀野怪获取金币，用于刷新商店和买牌；3张同名同星手牌合成升一星；在有地形与天气的大地图自由建设，特定建筑保留位置要求。详细规则见[60分钟战役规则](design/gdd/sixty-minute-campaign-system.md)与[商店升星系统](design/gdd/kill-gold-card-shop-fusion-system.md)。当前可运行灰盒已接通60分钟倒计时、循环威胁、10分钟商店阶段与新版经济/合成；完整60分钟难度和经济仍待自然试玩调平。

> 继续开发前请先完整阅读 [DEVELOPMENT_PROGRESS.md](DEVELOPMENT_PROGRESS.md)。该文档记录当前进度、下一步、验证基线和跨电脑接力步骤；每次开发结束后必须更新。

## 当前阶段

项目处于制作阶段，已完成：

- 核心玩法、60分钟连续守城、克制、怪物王和黄金凤凰GDD；微信广告设计已停用。
- Godot 4.7开发验证环境；Steam桌面交付仍待规划和验证。
- 960×540横屏兼容渲染配置。
- 全局对局状态与可启动的灰盒入口场景。
- 第1波野狼生成、移动、攻击主城与失败重置闭环。
- 箭塔自动索敌、野狼克制伤害、死亡与首波清场结算闭环。
- 20秒开局选卡、固定3张资源与3张防御卡，免费选四；迎战后才从底部手牌拖放建造。
- 中心主城与四边随机出生；树林/农田/金矿脉/石矿脉对应四种资源建筑，资源卡只能在匹配地点部署。
- 防御优先的岗位分配、人口食物消耗、饥饿标记和幂等波末结算。
- 开局5名农民占5/5人口，采集后运回主城才到账；每趟木/食/石2、金1。运输不中断于商店，死亡丢失携货并清理实际岗位。
- 民屋增加2人口容量；主城招募1农民消耗10金和1空闲人口容量，失败原因可见。
- 免费选四和连续守城期间都可调整逐建筑岗位并自动分配；战斗中通过“商店 / 岗位”面板操作，防御和持续产出立即按新岗位运行。
- 建造材料不足时弹出独立提示，明确显示建筑名称、缺少资源和差额，失败不会消耗卡牌或占用格位。
- 六卡区只负责选择；点击迎战进入怪潮后，底部部署手牌栏才出现，玩家可在战斗中拖牌到地图生成建筑。
- 免费选四确认后进入60分钟连续守城；十份怪潮作为循环威胁模板，清场自动衔接下一轮，不再有可无限等待的波间休整。
- 第2～10份怪潮数据均可生成、战斗和幂等清场结算；第10轮后循环使用第1份模板。
- 战斗商店刷新费用按2、3、4、5、6、6……递增；每10分钟威胁阶段重置为2金币并补满六格。
- 六张牌购买后立即入库存；刷新重抽全部六格并清除售罄状态，同名卡可重复购买，金币不足或库存满时保持原状态。
- 清场后自动衔接下一轮，战斗商店按玩家需要开关，不再要求波间“迎战”确认。
- 城墙卡可拖到地图任意合法空位并支持多面独立城墙；路线外墙不隔空阻挡，野狼优先攻击前方最近路线墙，破墙后继续寻找下一面墙或主城。
- 箭塔、兵营、城墙和民屋可自由落在没有单位的合法空地；兵营2岗位生成守卫，路线附近一对一拦截，波末消失、下波满血重生。同类建筑已支持多实例。
- 怪潮中可随时打开六卡战斗商店，购买立即进入最多18张的星级手牌，刷新费用按2～6封顶；商店打开期间敌人、生产和60分钟计时不会暂停。
- 手牌卡显示星级与同名同星数量；凑齐3张时可右键手动合成，原型最高3星。
- 六张商店牌从可玩建筑卡池抽取，包括民屋与石矿场；付费刷新重抽六格，已购位置恢复可买。
- 敌人选择进攻路线中最近的建筑或农民；被摧毁建筑释放资源点，携货幸存者仍可返回交付。

当前处于制作阶段：60分钟循环守城、商店/合成、运输与岗位已接通；Story-031已接入4608×2592分层高清地图、独立地图视口及山区道路/石梯通行。2026-10-17分叉三支路与按目的地最短选路已验，东南土路断点修复，全量34组1467项与GL15项通过；旧穿崖短路结论撤销。下一步优先首次寻路尖峰、动态避让和自然长局平衡。详见[最新分叉QA](tests/reports/qa-2026-10-17-junction-routes.md)；广告与微信排行榜停止排期。

## 本地运行

1. 使用Godot 4.7 Standard打开当前开发工程。
2. 在Godot项目管理器中导入本仓库根目录。
3. 打开项目后按F6/F5运行主场景。

若Godot已加入PATH，可执行：

```powershell
godot --path . --editor
```

工程结构冒烟检查：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\check_project.ps1
```

自动化回归（2026-09-11记录基线：21组、860项断言；本次方向调整未重跑玩法测试）：

```powershell
godot --headless --editor --quit --path .
pwsh -File .\tools\run_tests.ps1 -GodotPath '本机Godot控制台程序完整路径'
```

定点运行加 `-Filter 'test_settlement*'`。脚本输出日志到忽略目录 `.codex-temp/`；验证边界见 [十波QA报告](tests/reports/qa-2026-09-11-story-018.md)。
