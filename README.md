# Waiting for Dawn（等待黎明）

一款面向微信小游戏的2D像素卡牌塔防游戏。玩家在持续十波的黑夜中经营聚落、构筑防线、收集怪物王对策并守住主城。

> 继续开发前请先完整阅读 [DEVELOPMENT_PROGRESS.md](DEVELOPMENT_PROGRESS.md)。该文档记录当前进度、下一步、验证基线和跨电脑接力步骤；每次开发结束后必须更新。

## 当前阶段

项目处于制作阶段，已完成：

- 核心玩法、单夜十波、克制、怪物王、黄金凤凰和广告商业化GDD。
- Godot 4.7开发验证环境；微信导出最终版本待复核。
- 960×540横屏兼容渲染配置。
- 全局对局状态与可启动的灰盒入口场景。
- 第1波野狼生成、移动、攻击主城与失败重置闭环。
- 箭塔自动索敌、野狼克制伤害、死亡与首波清场结算闭环。
- 20秒开局选卡、固定3张资源与3张防御卡，免费选四；迎战后才从底部手牌拖放建造。
- 中心主城与四边随机出生；树林/农田/金矿脉/石矿脉对应四种资源建筑，资源卡只能在匹配地点部署。
- 防御优先的岗位分配、人口食物消耗、饥饿标记和幂等波末结算。
- 开局5名农民占5/5人口，采集后运回主城才到账；每趟木/食/石2、金1。运输不中断于商店，死亡丢失携货并清理实际岗位。
- 民屋增加2人口容量；主城招募1农民消耗10金和1空闲人口容量，失败原因可见。
- 白天与波间的逐建筑岗位加减、自动分配、战斗锁定，以及按实际岗位启停防御和持续产出。
- 建造材料不足时弹出独立提示，明确显示建筑名称、缺少资源和差额，失败不会消耗卡牌或占用格位。
- 六卡区只负责选择；点击迎战进入怪潮后，底部部署手牌栏才出现，玩家可在战斗中拖牌到地图生成建筑。
- 第1波清场后开放第2波六卡商店，免费选择2张；未使用旧牌跨波保留并与新牌合并，岗位可在波间调整。
- 第2波使用独立的5只野狼怪潮数据，可完成生成、战斗、清场、生产结算并推进至第3波休整。
- 第3波继续免费选择2张；第2～3波可花金币无限刷新未选牌，费用按10、15、20、25、30……递增，已选牌与免费额度保持不变。
- 第3波使用独立的6只野狼怪潮数据，清场结算后停在第4波休整。
- 第4波进入金币购买商店：六张牌可买0～6张，购买立即入库存，售罄牌不会被刷新覆盖，金币不足或库存满时保持原状态。
- 购买0张时首次点击迎战会提示风险；第4波暂用4狼功能验证编成，清场后进入第5波休整。
- 城墙卡可拖到地图任意合法空位并支持多面独立城墙；路线外墙不隔空阻挡，野狼优先攻击前方最近路线墙，破墙后继续寻找下一面墙或主城。
- 箭塔、兵营、城墙和民屋可自由落在没有单位的合法空地；兵营2岗位生成守卫，路线附近一对一拦截，波末消失、下波满血重生。当前箭塔、兵营仍各限一座。
- 怪潮中可随时打开六卡战斗商店，购买立即进入手牌，刷新费用按10、15、20……递增；商店打开期间敌人和持续生产不会暂停，同波重开保留牌面、售罄和刷新价格。
- 六张商店牌从8种建筑卡中抽取，包括民屋与石矿场；付费刷新可抽到原六张之外的牌，已选/已购槽位保持不变。
- 敌人选择进攻路线中最近的建筑或农民；被摧毁建筑释放资源点，携货幸存者仍可返回交付。

Story-015～017已完成灰盒收尾。下一目标为Story-018：先试玩新经济下的前四波，再实现第5～10波与后期10%压力曲线。当前尚不能完整通关十波，也没有接入广告和排行榜。

## 本地运行

1. 使用Godot 4.7 Standard打开当前开发工程。
2. 在Godot项目管理器中导入本仓库根目录。
3. 打开项目后按F6/F5运行主场景。

若Godot已加入PATH，可执行：

```powershell
godot --path . --editor
```

工程结构冒烟检查：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\check_project.ps1
```

自动化回归（当前19组、613项断言）：

```powershell
godot --headless --editor --quit --path .
pwsh -File .\tools\run_tests.ps1 -GodotPath '本机Godot控制台程序完整路径'
```

定点运行加 `-Filter 'test_settlement*'`。脚本输出日志到忽略目录 `.codex-temp/`；验证边界见 [本次QA报告](tests/reports/qa-2026-09-06.md)。
